# 2336. 无限集中的最小数字

## 算法

维护尚未顺序弹出的最小整数 `next_number`，以及一个最小堆保存被加回且小于 `next_number` 的数字，辅助集合防止重复入堆。弹出时优先取堆顶；若堆为空，返回 `next_number` 并递增。加回数字仅当它已经被弹出且当前未在堆中时才入堆。

## 正确性说明

所有不小于 `next_number` 的正整数从未被顺序弹出，天然仍在集合中；所有更小但被加回的数字完整保存在最小堆中。堆顶若存在必小于 `next_number`，所以优先弹出堆顶得到集合最小值；否则 `next_number` 就是最小值。`addBack` 只恢复已被弹出的数且去重，始终保持该表示不变，因此所有操作正确。

## 复杂度分析

`popSmallest` 在弹出加回数字时为 `O(log a)`，否则为 `O(1)`；`addBack` 为 `O(log a)`，其中 `a` 是加回堆大小。空间复杂度为 `O(a)`。

## 边界情况

- 加回一个仍在集合中的大数字不会重复添加。
- 同一数字多次加回只保留一个实例。
- 堆为空时会继续按 1、2、3……顺序生成数字。
