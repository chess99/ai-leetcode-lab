# 2295. 替换数组中的元素

## 算法

建立“元素值到数组下标”的哈希表。对每次替换 `[old, new]`，通过哈希表在常数时间找到 `old` 所在下标，修改数组该位置，并在哈希表中删除旧键、加入新键。操作结束后直接返回数组。

## 正确性说明

初始数组元素互不相同，哈希表准确记录每个值的位置。每次操作保证旧值存在且新值不存在，因此修改后只需同步更新这一项映射，哈希表仍准确对应当前数组。归纳可知每个操作都恰好替换指定元素，最终数组正确。

## 复杂度分析

建表耗时 `O(n)`，每次替换平均 `O(1)`，总时间复杂度为 `O(n + m)`；哈希表空间复杂度为 `O(n)`。

## 边界情况

- 新值可以在后续操作中再被替换，映射会同步更新。
- 操作保证新值当前不存在，不会发生下标冲突。
- 数组顺序始终保持不变，只替换对应位置的值。
