## 思路

遍历 81 个格子，忽略空格。对每个数字构造三类唯一键：行和数字、列和数字、3×3 宫和数字。若任意键已出现，说明对应规则被违反；否则把三类键加入集合。宫坐标由 `row // 3` 和 `column // 3` 确定。

## 复杂度

- 时间复杂度：O(1)，棋盘固定为 9×9；泛化表示为 O(n²)。
- 空间复杂度：O(1)，最多记录 243 个键。

## 边界条件与本地验证

- `'.'` 不参与任何重复判断。
- 同一数字分别在行、列、宫中重复都会立即返回 `False`。
- 只验证当前填入内容的合法性，不要求棋盘可解。
- 验证了题目给出的有效棋盘为 `True`，将左上角首格改为 `"8"` 后为 `False`，以及单行重复数字为 `False`。
