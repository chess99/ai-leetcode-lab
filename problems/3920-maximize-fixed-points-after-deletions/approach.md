## 算法

设原下标为 `i` 的元素最终成为固定点，那么它在保留数组中的下标必须是 `nums[i]`。

依次选出的固定点记为 `(i, v)`，其中 `v = nums[i]`。相邻两个固定点 `(i1, v1)`、`(i2, v2)` 能同时出现，当且仅当：

- `i1 < i2`；
- `v1 < v2`；
- 两者之间有足够多的原元素充当保留元素，即 `v2-v1 <= i2-i1`。

令 `d = i-v`，最后一个条件等价于 `d1 <= d2`；第一个固定点前能填满 `v` 个位置又等价于 `d >= 0`。因此问题变成：在所有 `v <= i` 的点 `(v, i-v)` 中，求第一维严格递增、第二维不下降的最长链。

按 `v` 从小到大分组，用树状数组维护每个 `d` 前缀内的最长链。相同 `v` 的点先全部查询、再统一更新，从而保证第一维严格递增。

## 正确性

任取一个删除方案，并按原下标列出其中的固定点。它们的新下标就是各自的值，所以值严格递增。两个相邻固定点之间需要保留 `v2-v1-1` 个元素，而原数组对应区间中共有 `i2-i1-1` 个可选元素，因此必有 `i2-v2 >= i1-v1`；第一个固定点同理满足 `i-v >= 0`。故任意方案的固定点都对应算法所求偏序中的一条链。

反过来，任取一条满足值严格递增且 `i-v` 不下降的链。第一个点之前至少有 `v` 个元素；每两个相邻点之间至少有 `v2-v1-1` 个元素。分别保留任意所需数量的这些填充元素，就能让每个链上元素恰好落在下标 `v`，全部成为固定点。因此每条链都能构造出合法删除方案。

树状数组转移枚举了所有第二维不大于当前点的较早值组，恰好计算上述最长链，所以返回值最优。

## 复杂度

时间复杂度为 `O(n log n)`，空间复杂度为 `O(n)`。
