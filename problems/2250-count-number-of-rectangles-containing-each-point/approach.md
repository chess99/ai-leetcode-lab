# 2250. 统计包含每个点的矩形数目

## 算法

矩形高度最大为 100。按高度建立 101 个桶，每个桶存放该高度所有矩形的宽度并排序。查询点 `(x, y)` 时，只有高度不小于 `y` 的矩形可能包含它；对每个高度桶用二分查找第一个宽度不小于 `x` 的位置，桶中其后的矩形全部满足条件，将数量相加。

## 正确性说明

一个左下角固定为原点的矩形包含点 `(x, y)`，当且仅当它的高度至少为 `y` 且宽度至少为 `x`。算法遍历了全部可能高度，并通过有序宽度桶准确计算每个高度中满足宽度条件的矩形数。每个矩形恰属于一个高度桶，因此总和既不遗漏也不重复，结果正确。

## 复杂度分析

排序所有桶的总时间为 `O(R log R)`。每个查询最多遍历 100 个高度且各做一次二分，时间为 `O(100 log R)`；空间复杂度为 `O(R)`。

## 边界情况

- 点在矩形边界上时，`>=` 条件使其被计入。
- 点的纵坐标较高时，只检查不低于它的高度桶。
- 某个高度没有矩形时，对空桶二分并贡献 0。
