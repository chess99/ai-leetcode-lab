## 思路

在题目提供的 MySQL 函数中，先把 N 减一转换为零基偏移，再对工资去重并按降序排列，使用 MySQL 的 `LIMIT N, 1` 取一行。函数的标量 `RETURN` 在不足 N 个不同工资时返回 `NULL`，符合要求，无需额外分支。避免把 `OFFSET N - 1` 直接写在 LIMIT 中，因为 MySQL 对存储函数参数的偏移表达式语法支持有限。

## 复杂度

去重和排序成本由数据库执行计划决定；返回值只取一行，额外结果空间为 `O(1)`。

## 边界条件与本地验证

- `N = 1` 应取最高不同工资。
- 重复工资不能挤占名次。
- 不足 `N` 个不同工资时函数应返回 `NULL`。
