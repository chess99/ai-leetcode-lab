# 解题记录

## 思路

对每个分割点记录差值 `2*prefix-total`。扫描可能被替换的位置，左计数器保存其左侧分割点，右计数器保存其右侧分割点。把当前值 `x` 改为 `k`，差量为 `delta=k-x`：左侧分割点需要原差值为 `delta`，右侧需要为 `-delta`。两者计数相加并与不替换时的答案取最大。

## 复杂度

差值用单次前缀扫描构造，整体时间 `O(n)`，两个计数器空间 `O(n)`。

## 边界条件与本地验证

必须包含不替换的情况，负数和零差值都可直接作为哈希键。题面样例通过；随机小数组逐个尝试不替换或替换一个位置并枚举全部分割点，对拍 1000 组。本次审计把原先反复求切片和的 `O(n²)` 构造改为 `O(n)`。
