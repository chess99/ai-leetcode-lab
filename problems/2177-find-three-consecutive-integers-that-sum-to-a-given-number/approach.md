# 2177. 找到和为给定整数的三个连续整数

## 算法

设三个连续整数的中间数为 `middle`，三数为 `middle - 1`、`middle`、`middle + 1`，它们的和为 `3 * middle`。因此仅当 `num` 能被 3 整除时有解，此时直接令 `middle = num // 3` 并返回这三个数。

## 正确性说明

任意三个连续整数都可唯一写作 `middle - 1`、`middle`、`middle + 1`，其和恒为 `3 * middle`，故有解必要求 `num` 是 3 的倍数。若可整除，算法构造的三数之和正好为 `num` 且彼此连续，故结果正确。

## 复杂度分析

只进行常数次算术运算，时间复杂度为 `O(1)`，空间复杂度为 `O(1)`。

## 边界情况

- `num = 0` 时返回 `[-1, 0, 1]`。
- 非 3 的倍数时返回空数组。
- 题目上界很大，但 Python 整数可直接处理。
