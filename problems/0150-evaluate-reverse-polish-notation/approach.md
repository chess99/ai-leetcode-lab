## 思路

顺序扫描 token。数字压栈；遇到运算符时依次弹出右、左操作数，计算后把结果压回。除法显式使用绝对值整除并按符号恢复，以实现向零截断而不依赖浮点运算。

## 复杂度

每个 token 处理一次，时间复杂度为 `O(n)`；栈最多容纳所有数字，空间复杂度为 `O(n)`。

## 边界条件与本地验证

- 弹栈顺序为右操作数在前、左操作数在后。
- 负数除法必须向零截断，而非 Python 的向下取整。
- 单个数字 token 直接成为答案。

本地断言三个示例，并验证 `-7 / 3 -> -2`、`7 / -3 -> -2` 和单数字输入；同时通过 `py_compile` 语法检查。
