# 2095. 删除链表的中间节点

## 思路

使用快慢指针。`slow` 每轮走一步，`fast` 每轮走两步，同时记录 `slow` 的前驱 `previous`。当 `fast` 到达链表末尾时，`slow` 恰好位于下标 `n // 2` 的中间节点，将 `previous.next` 指向 `slow.next` 即可跳过该节点。单节点链表直接返回空链表。

### 正确性说明

每轮快指针比慢指针多走一步。当快指针无法再走两步时，它已走过的距离是慢指针的两倍，慢指针所处位置正是长度为 `n` 的链表中下标 `n // 2` 的节点。前驱节点的 `next` 改指向中间节点的后继后，其他节点相对顺序不变且中间节点不可达，因此返回链表恰好删除了要求的节点。

## 复杂度

快慢指针只进行一次遍历，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## 边界条件与本地验证

- 单节点链表的中间节点就是头节点，删除后返回空链表。
- 偶数长度链表会删除下标 `n // 2` 的右侧中间节点。
- 两节点链表会保留第一个节点。
