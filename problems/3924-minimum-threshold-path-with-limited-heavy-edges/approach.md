## sol-medium 交接

本次由 `sol-medium` 接手 `terra-medium` 的失败候选，并保留最初创建者署名。

最新远判在以下用例失败：

```text
n = 2, edges = [[0,1,45]], source = 0, target = 1, k = 1
旧输出 = 45，期望 = 0
```

根因不是 0-1 BFS，而是二分候选集合只包含已有边权。阈值允许为 `0`；当路径上的正权边都可作为不超过 `k` 条重边使用时，答案可以是 `0`，即使图中没有权重为 0 的边。

## 新思路

答案只可能是 `0` 或某个已有边权：阈值处于两个相邻边权之间时，每条边的轻重分类不变，因此可行性也不变。于是对去重排序后的候选集合 `{0} ∪ {所有边权}` 二分。

固定候选阈值 `t`，把权重 `<= t` 的边费用视为 0，把权重 `> t` 的边费用视为 1。用 0-1 BFS 求 `source` 到各点所需的最少重边数；目标点的最少重边数不超过 `k` 时，`t` 可行。随着阈值增大，重边只会变少，所以该判定具有单调性。

题面要求在函数中途保存输入，代码使用变量 `tarnicuvo` 完成该要求。

## 正确性证明

**引理 1：** 对固定阈值 `t`，0-1 BFS 得到的 `heavy_count[v]` 是从 `source` 到 `v` 的路径中重边数的最小值。

证明：每条轻边费用为 0、重边费用为 1，路径费用恰好等于路径中的重边数。0-1 BFS 在只含 0/1 边权的图上计算最短路，因此结论成立。

**引理 2：** `feasible(t)` 为真，当且仅当阈值 `t` 下存在一条有效路径。

证明：由引理 1，`heavy_count[target]` 是所有源点到目标点路径中的最少重边数。它不超过 `k`，恰好等价于至少存在一条至多含 `k` 条重边的路径。

**引理 3：** 若最小可行阈值不是 0，则它一定等于某条边的权重。

证明：若正阈值 `t` 不等于任何边权，则可以把它降低到不超过 `t` 的最大边权；期间没有边改变轻重分类，由引理 2，可行性不变，与 `t` 最小矛盾。

**定理：** 算法返回题目要求的最小阈值，不存在路径时返回 -1。

证明：由引理 3，最优答案包含在候选集合中；由引理 2，可行性随候选阈值单调不减。二分因此找到最小可行候选。若所有候选都不可行，则源点与目标点不连通，算法保留并返回 -1。

## 复杂度

设 `m = edges.length`。候选数至多 `m + 1`，每次 0-1 BFS 为 `O(n + m)`：

- 时间：`O((n + m) log(m + 1))`
- 空间：`O(n + m)`

## 边界条件与本地验证

- `source == target`：空路径直接返回 0。
- 无边或源点、目标点不连通：返回 -1。
- `k == 0`：退化为只允许使用轻边。
- `k` 足以覆盖某条路径的全部边：最优阈值可以为 0，这正是旧候选遗漏的情况。
- 平行边、自环、重复权重不影响算法。

本地验证结果：

- Python AST 解析与动态编译通过。
- 题面 3 个样例分别得到 `4`、`-1`、`0`。
- 最新失败反例得到 `0`；同一单边图在 `k = 0` 时得到 `45`。
- 使用独立暴力 oracle 枚举小图中的所有简单路径，并按路径的第 `k + 1` 大边权计算最优阈值；固定随机种子下共对拍 3500 组，全部一致。随机数据覆盖无边、非连通、自环、平行边和重复权重。
- 最大约束 `n = 1000, m = 1000` 的两组验证通过：`k = 0` 得到 `10^9`，`k = 1000` 得到 `0`；本机单次耗时分别约 `0.0005s`、`0.0004s`。
