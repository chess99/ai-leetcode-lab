# 2285. 道路的最大总重要性

## 思路

先统计每座城市连接道路的数量，即度数。所有道路重要性之和可改写为“每座城市分配的值乘以其度数”的总和。将度数升序排序后，依次分配 `1` 到 `n`，即可使较大的度数获得较大的值，计算点积作为答案。

### 正确性说明

每条道路的两个端点值各被计入一次，因此总重要性等于所有城市的“度数 × 分配值”之和。若存在两个城市度数 `d1 < d2` 却分配值 `v1 > v2`，交换二者分配值后，总和增加 `(d2 - d1) * (v1 - v2) >= 0`。不断消除这类逆序，得到按度数和分配值同序的方案，且不会变差。算法正是该最优同序分配，故结果最大。

## 复杂度

统计度数为 `O(n + m)`，排序为 `O(n log n)`，总时间复杂度为 `O(n log n + m)`，空间复杂度为 `O(n)`。

## 边界条件与本地验证

- 度数为 0 的城市会获得较小值但不影响答案。
- 多个城市度数相同，交换其分配值不会改变总重要性。
- 图不必连通，统计方式仍然适用。
