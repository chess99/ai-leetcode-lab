## 失败根因

原解把“选择哪些行、哪些列”当成了方案本身。当 `k = n²` 时，只要选中全部行或全部列，最终棋盘都会全黑；这些不同选择过程实际是同一个最终涂色方案。例如 `n=2, k=4` 被旧代码重复计为 7，正确答案只有 1。

## 思路

若 `k = n²`，直接返回 1。

否则最终棋盘不可能选中全部行或全部列。枚举被涂黑的行数 `rows` 和列数 `columns`，二者只需取 `0..n-1`。黑格数为：

`rows * n + columns * n - rows * columns`

当它等于 `k` 时，行集合和列集合都能从最终棋盘唯一恢复，贡献为 `C(n, rows) * C(n, columns)`。

## 正确性证明

对于非全黑棋盘，至少存在一条未选中的行和一条未选中的列。任一被选中的行整行全黑；任一未选中的行中，恰好只有被选中的列为黑色。因此最终棋盘唯一确定所选行集合与列集合，不会重复计数。枚举覆盖所有行列集合，并仅在黑格数等于 `k` 时累加，故恰好统计全部合法方案。

全黑棋盘虽能由多种行列选择产生，但题意按最终格子颜色区分方案，故只有一种，单独返回 1 正确。

## 复杂度

时间复杂度 `O(n²)`，额外空间复杂度 `O(1)`。

## 本地验证

覆盖样例、`k=0`、`k=n²`，以及全部 `1 <= n <= 6`、`0 <= k <= n²`。独立 oracle 枚举所有行列子集，将最终棋盘去重后按黑格数统计，结果全部一致。
