# 解题记录

## 思路

记忆化搜索状态 `(i,j,diff)`，其中差值表示第一串已解析但尚未与第二串匹配的通配长度。遇数字时可读取连续数字的 1 到 3 位并增减差值；差值为正时用第二串一个字母抵消，为负时用第一串字母抵消；差值为零时两侧字母必须相同。

## 复杂度

设可达差值范围大小为 `D`，状态数 `O(n*m*D)`，每个状态数字分支至多 3 个；时间和记忆空间均为 `O(n*m*D)`，递归深度 `O(n+m)`。

## 边界条件与本地验证

连续数字存在多种拆分，差值可正可负，末尾必须恰好归零。题面真假样例通过；另对一组长度较小的编码显式展开所有可能原串集合，两两核对是否有交集。
