## 思路

按题面要求用 `tarmiqusve` 保存输入。把非零单元格按值从大到小分组处理，并用二维树状
数组记录所有已经处理过的位置；查询某个值 `x` 时，结构中恰好只有值严格大于 `x` 的格子。

对候选格子查询以其为中心、行列距离都不超过 `x` 的裁剪矩形中有多少更大值，再减去
四个同时满足行距离与列距离恰为 `x` 的有效角点。剩余数量为 0 时它是局部最大值。同值
整组查询完成后才加入结构，保证相等值不会相互否决。

## 复杂度

令单元格数为 `N=n*m`，排序时间 `O(N log N)`，每次二维树状数组操作
`O(log n log m)`；空间复杂度 `O(N)`。

## 边界条件与本地验证

值为 0 的格子永远不是候选；矩阵边界外的角点不参与减法；只有四个“行列距离同时等于
x”的位置被忽略，并非整个边框。验证四个题面样例，并与小矩阵逐格扫描邻域的暴力结果对拍。
