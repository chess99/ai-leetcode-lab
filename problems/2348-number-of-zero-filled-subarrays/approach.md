## 思路

从左到右扫描并维护以当前位置结尾的连续 0 长度 `consecutive_zeros`。若当前值为 0，则以当前位置为右端点的全 0 子数组有恰好 `consecutive_zeros` 个，累加到答案；若当前值非 0，则这些子数组不能跨过当前位置，将连续长度清零。

## 复杂度

数组只扫描一次，时间复杂度为 `O(n)`；只使用两个整数变量，额外空间复杂度为 `O(1)`。

## 边界条件与本地验证

- 单个 0 会贡献一个子数组。
- 长度为 `L` 的连续 0 段会在扫描中累计 `1 + 2 + ... + L = L(L+1)/2` 个子数组。
- 非 0（包括负数）都会中断连续段。
- 已验证题面三组样例，分别返回 `6`、`9`、`0`。
- 已验证边界：`[0]` 返回 `1`，`[0,0,0]` 返回 `6`。
