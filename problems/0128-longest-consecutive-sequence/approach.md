# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

把所有数字放入集合以实现 O(1) 平均查找。仅当 `value - 1` 不在集合中时才把它作为连续序列起点，随后不断查找 `value + 1`、`value + 2` 等并计数。每个元素只会在某个序列的扩展中被访问一次。

## 复杂度

- 时间复杂度：O(n)，集合操作为平均 O(1)。
- 空间复杂度：O(n)。

## 边界条件与本地验证

- 空数组返回 0；重复数会被集合自然去重。
- 支持负数和分散的多段序列。
- 验证：`[100,4,200,1,3,2] -> 4`、`[0,3,7,2,5,8,4,6,0,1] -> 9`、`[1,0,1,2] -> 3`、`[] -> 0`。
