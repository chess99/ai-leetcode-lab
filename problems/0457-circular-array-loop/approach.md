## 思路

以每个下标为起点，固定该起点的移动方向，使用 Floyd 快慢指针沿环形数组前进。每次移动前均检查慢指针、快指针和快指针的下一跳是否仍为同一方向；一旦方向改变，该路径不可能是合法循环。快慢指针相遇时，再排除下一跳仍为自身的单元素环，剩余相遇即为长度大于 1 的合法循环。

## 复杂度

每个起点最多进行 `O(n)` 次探测，时间复杂度 `O(n^2)`；除几个下标变量外不使用额外容器，空间复杂度 `O(1)`。在题目 `n <= 5000` 的范围内可行。

## 边界条件与本地验证

- 单元素自环（移动步数是数组长度的倍数）不合法，需显式排除。
- 循环内混入正负两种方向不合法。
- 验证了 `[2,-1,1,2,2] -> True`、`[-1,-2,-3,-4,-5,6] -> False`、`[1,-1,5,1,4] -> True` 和 `[-1,2] -> False`。
