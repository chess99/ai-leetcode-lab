## 算法

先按入队时刻排序任务，并用最小堆保存当前已入队但尚未执行的任务，堆键为 `(处理时间, 原下标)`。CPU 空闲且堆为空时，时间跳到下一任务入队时刻；将所有已到达任务加入堆，弹出处理时间最短、下标最小的任务执行，并将当前时间增加其处理时间，直到完成全部任务。

## 正确性

每次开始执行前，算法将所有入队时刻不晚于当前时间的任务加入堆，因此堆恰是 CPU 可选择的任务集合。堆的排序键与题目“最短处理时间、再最小下标”的规则完全一致，弹出的任务就是 CPU 必须选择的任务。时间跳跃只发生在没有可执行任务时，不改变任何选择。归纳地模拟每次执行，得到的顺序正确。

## 复杂度

排序耗时 `O(n log n)`；每项任务入堆、出堆各一次，总时间 `O(n log n)`，堆和排序数组空间复杂度为 `O(n)`。

## 边界

CPU 在任务之间空闲时直接跳到下一入队时刻；处理时间相等的任务由原下标稳定决胜。
