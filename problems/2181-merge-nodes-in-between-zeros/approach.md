# 2181. 合并零之间的节点

## 思路

## 算法

跳过起始的 0，顺序遍历链表并累加非零节点值。遇到 0 时，当前累加值就是该分段的和，创建一个新节点接到结果链表尾部，然后将累加器清零。遍历结束后返回哨兵节点后的结果链表。

## 正确性说明

输入中的每一段非零节点都被相邻的两个 0 唯一界定。算法在段内恰好把每个节点值累加一次，并在右侧分隔 0 出现时写出一个对应的和节点；不会把不同段的值混合。起始、末尾分隔 0 都不会写入结果，因此结果链表恰好包含每段的和且不含 0。

## 复杂度分析

原链表只遍历一次，时间复杂度为 `O(n)`。结果链表包含每个分段一个新节点，额外空间复杂度为 `O(k)`，其中 `k` 为分段数量。

## 边界情况

- 只有一个分段时，结果链表只有一个节点。
- 分段可包含多个非零节点，都会被累加。
- 题目保证不存在连续的分隔 0，因此每个输出节点的和为正数。
