## 算法

定义记忆化函数 `power(x)` 计算 `x` 按 Collatz 规则变为 1 的步数：`x = 1` 时为 0；偶数转移到 `x / 2`，奇数转移到 `3x + 1`，并在结果上加 1。对区间 `[lo, hi]` 的每个整数按键 `(power(x), x)` 升序排序，返回第 `k` 个值。

## 正确性

`power` 的递推恰好对应题目每一步的转移，基例 `power(1) = 0` 正确，因此它返回的就是每个整数的权重。排序键的第一项保证权重从小到大，第二项保证权重相同时数值从小到大，完全符合题目排序规则。故排序结果的第 `k` 个元素即为所求。

## 复杂度

设区间长度为 `m`，不同 Collatz 状态的总计算步数为 `S`。缓存使每个访问到的状态至多计算一次，计算权重耗时 `O(S)`；排序耗时 `O(m log m)`。缓存和排序数组的空间复杂度为 `O(S + m)`。

## 边界

`lo = hi` 时直接返回该唯一整数。权重相同的数使用数值作为次关键字稳定地打破平局；缓存也覆盖了区间外的中间状态。
