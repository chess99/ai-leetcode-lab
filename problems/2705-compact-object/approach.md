## 思路

递归处理 JSON 值。数组先删除假值，再递归处理保留下来的元素；普通对象遍历键值对，仅保留原值为真的键并递归压缩其值；原始真值直接返回。判定必须基于压缩前的值，因此空数组和空对象仍会被保留。

## 复杂度

时间复杂度 `O(N)`，其中 `N` 为 JSON 中的值和键数量；递归栈空间为嵌套深度 `O(D)`，返回结果占 `O(N)`。

## 边界条件与本地验证

`null` 是假值；`0`、`false` 和空字符串会删除；空数组、空对象本身为真值，压缩后即使为空也保留。
