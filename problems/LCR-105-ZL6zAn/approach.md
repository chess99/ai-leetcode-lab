# 解题记录

- Profile：terra-medium
- 轮次：1

## 思路

逐格寻找尚未访问的陆地。发现值为 1 的格子后立即改为 0 并压入栈，随后做四方向深度优先遍历：每弹出一个格子就累计面积，把相邻且仍为 1 的格子在入栈时标记为 0，避免重复加入。一次搜索恰好覆盖一个岛屿，用其面积更新全局最大值。直接复用输入矩阵作为访问标记，避免额外布尔矩阵。

## 复杂度

设网格为 `m x n`，每个格子至多入栈一次，时间复杂度为 `O(mn)`；显式栈在最坏情况下保存 `O(mn)` 个陆地格，空间复杂度为 `O(mn)`。

## 边界条件与本地验证

全水网格从不启动搜索并返回 0；单格陆地面积为 1；对角相邻不属于同一岛屿；算法会把访问过的陆地改为 0，这是题目允许的内部处理。本地验证全水、全陆、多个岛、细长岛和仅对角接触，并对随机小网格用独立访问集合的朴素连通分量搜索比较最大面积。
