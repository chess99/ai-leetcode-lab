## 思路

使用 MySQL REGEXP_LIKE 完整匹配四段 IPv4。每段只允许 0、无前导零的 1~99、100~199、200~249、250~255；不匹配者按 ip 分组计数，并按题意双降序排序。

## 复杂度

对 N 行日志，匹配与聚合时间近似 O(N*L)，L 为 IP 字符串长度；聚合空间 O(U)。

## 边界条件与本地验证

锚点保证不能多段或少段，分段模式同时拒绝空段、前导零和超过255。SQL 保留完整署名并使用 MySQL 8 正则函数。
