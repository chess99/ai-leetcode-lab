# 面试题 04.02. 最小高度树

- 难度：EASY
- 标签：树, 二叉搜索树, 数组, 分治, 二叉树
- 来源：https://leetcode.cn/problems/minimum-height-tree-lcci/
- 归档：2026-08-11T15:57:16Z

## 题目

<p>给定一个有序整数数组，元素各不相同且按升序排列，编写一个算法，创建一棵高度最小的二叉搜索树。</p>
<strong>示例：</strong>

<pre>
给定有序数组: [-10,-3,0,5,9],

一个可能的答案是：[0,-3,9,-10,null,5]，它可以表示下面这个高度平衡二叉搜索树：

          0
         / \
       -3   9
       /   /
     -10  5
</pre>


## 样例输入

```text
[-10,-3,0,5,9]
```
