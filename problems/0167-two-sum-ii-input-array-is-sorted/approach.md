# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

使用指向有序数组两端的双指针。当前和过小时左指针右移以增大和，过大时右指针左移以减小和；命中时返回转换为 1 基的两个下标。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 支持负数及相同数值的两个不同位置。
- 题目保证唯一答案；验证 `[2,7,11,15],9 -> [1,2]`、`[2,3,4],6 -> [1,3]`、`[-1,0],-1 -> [1,2]`。
