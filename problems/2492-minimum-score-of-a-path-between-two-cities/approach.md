# 2492. 两个城市间路径的最小分数

## 思路

从城市 `1` 做广度优先搜索，访问它所在连通块的所有城市与道路，并记录其中最小的道路距离。

题目允许一条路径重复经过道路和城市。因此，只要一条道路位于城市 `1` 所在连通块中，就可以先从 `1` 走到该道路、经过它，再从该处走到城市 `n`；该道路距离即可成为这条路径的分数。故答案正是此连通块内的最小边权。

## 正确性说明

任意从城市 `1` 到城市 `n` 的路径只能使用城市 `1` 所在连通块中的道路，所以其分数不可能小于该连通块所有道路的最小距离 `m`。

反过来，取权重为 `m` 的道路。它的两个端点均在该连通块中，且城市 `n` 也在其中（题目保证 `1` 与 `n` 连通）。允许重复行走时，可从 `1` 到该道路的一端，经过该道路，再到 `n`，形成一条包含它的路径，分数为 `m`。因此最小可能分数就是 BFS 记录的值，算法正确。

## 复杂度

设城市 `1` 所在连通块有 `V` 个城市、`E` 条道路。建图和搜索时间复杂度为 `O(V + E)`（整体上不超过 `O(n + roads.length)`），空间复杂度为 `O(n + roads.length)`。

## 边界情况

- 图可能不连通，搜索只需处理城市 `1` 所在连通块。
- 最优路径可能需要先绕行并重复经过道路，不能只考虑简单路径。
- 只有一条连接 `1` 和 `n` 的道路时，直接得到该道路距离。
