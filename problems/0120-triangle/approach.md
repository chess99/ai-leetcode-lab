# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

从最后一行开始做自底向上的动态规划。`paths[column]` 保存当前位置下方子三角形的最小路径和；处理上一行时，当前值加上其两个相邻子节点最小值即可。每层覆盖更新同一个数组，最后首元素就是答案。

## 复杂度

- 时间复杂度：O(n²)，其中 n 为三角形行数。
- 空间复杂度：O(n)。

## 边界条件与本地验证

- 单行三角形直接返回该元素，支持负数。
- `paths[column + 1]` 在自底向上更新前仍保留右下子节点的值。
- 验证：`[[2],[3,4],[6,5,7],[4,1,8,3]] -> 11`、`[[-10]] -> -10`、`[[1],[-2,-3]] -> -2`。
