# 解题记录

## 思路

将图书表与借阅表按 `book_id` 连接，并在连接条件中只保留 `return_date IS NULL` 的当前借阅。按图书分组后统计未归还记录数，借阅数等于总副本数时说明没有可用副本。最后按当前借阅者数降序、书名升序排列。

## 复杂度

设图书数为 b、借阅记录数为 r。数据库使用索引和哈希/排序聚合时，主要处理成本约为 O(b + r)，最终排序最坏为 O(b log b)；结果聚合空间为 O(b)。

## 边界条件与本地验证

已归还记录不能计数，当前借阅数少于总副本数的图书应排除；没有当前借阅的图书也不会出现在内连接结果中。使用本地 SQLite 内存库执行题面样例，核对了输出列、计数和排序；SQL 语法与本题 MySQL 用法兼容。
