本候选重新实现同一类树形背包，但每个状态数组只保留当前子树实际可能达到的费用范围，并跳过不可达项；同时显式保存题面要求的中途输入快照 `blenorvask`。

## 算法

对每个员工 `u`，DFS 返回两个按“精确花费”索引的数组：

- `dp0[c]`：`u` 的直属上司没有买股票时，在 `u` 的整棵子树中恰好花费 `c` 的最大利润；
- `dp1[c]`：`u` 的直属上司买了股票时，对应的最大利润。

处理 `u` 的所有孩子时，先维护两个临时背包：

- `skipped`：假定 `u` 不买，孩子都不能打折，因此合并每个孩子的 `dp0`；
- `bought`：假定 `u` 会买，孩子都能打折，因此合并每个孩子的 `dp1`。

每次合并是截断到 `budget` 的最大加法卷积。孩子全部合并后：

- 不买 `u`：直接采用 `skipped`；
- 买 `u`：在 `bought` 的费用和利润上，加上 `u` 的买入费用及 `future[u] - price`。

若上司没买，`price = present[u]`；若上司买了，`price = floor(present[u] / 2)`。两种选择逐费用取最大值，即得到 `dp0` 和 `dp1`。CEO 没有上司，最终答案是根节点 `dp0` 中的最大值。

注意，即使当前员工单独交易亏损，也不能提前删除“买入”状态，因为买入可能为直属下属解锁折扣，从而使整棵子树的总利润更高。

## 正确性证明

对员工子树高度作归纳。

**归纳命题：** 对任意员工 `u`、任意上司购买状态 `s ∈ {0, 1}` 和任意费用 `c ≤ budget`，DFS 返回的 `dps[c]` 等于在 `u` 子树内恰好花费 `c` 的最大可得利润。

**基础情形：** `u` 是叶子。合法方案只有不买 `u`，或以上司状态决定的原价/折扣价买 `u`。`add_current` 正好枚举这两种方案并逐费用取最大值，所以命题成立。

**归纳步骤：** 假设命题对 `u` 的所有孩子成立。若不买 `u`，每个孩子的上司均未购买，孩子子树必须使用其 `dp0`；若买 `u`，每个孩子的上司均已购买，孩子子树必须使用其 `dp1`。不同孩子的子树互不相交，最大加法卷积枚举总费用在各孩子之间的所有分配，并由归纳假设取得每种分配下的最优利润。因此 `skipped` 和 `bought` 分别准确覆盖 `u` 不买、买入时的所有后代方案。最后加入 `u` 自身的两种选择，并按上司状态使用正确价格，便覆盖且只覆盖 `u` 子树中的全部合法方案。命题成立。

CEO 不享受折扣，故根节点采用 `dp0`；在所有不超过预算的精确费用中取最大值，就是全局最优利润。

## 复杂度

设 `B = budget`。每条父子边参与两次背包合并，每次最坏为 `O(B²)`，总时间复杂度为 `O(nB²)`。每个返回数组长度至多 `B + 1`，递归栈及状态总空间为 `O(nB)`；合并时的额外工作数组为 `O(B)`。

## 边界说明

- CEO 永远按原价判断，不会凭空获得折扣。
- 折扣价格使用整数除法，允许 `present[u] = 1` 时出现零成本买入。
- 精确费用状态保留负利润方案，因为它可能解锁后代折扣。
- 买入费用超过预算时只保留“不买”分支。
- 答案允许什么都不买，因此至少为 `0`。
- 链、星形树和最大深度 `160` 均在 Python 默认递归深度内。

## 本地验证

- 题面四个样例：`4 / 4` 通过。
- 固定随机种子 `3562`，对 `n = 1..10` 的随机树、价格、未来价格和预算，以枚举全部 `2^n` 个购买子集作为独立 oracle：`10,000 / 10,000` 通过。
- 五个定向边界（零价折扣、预算不足、全部亏损、连续零价折扣、亏损上司解锁高利润下属）：`5 / 5` 通过。其中最后一例确认算法会保留上司的负利润买入状态，并得到 oracle 一致的答案 `14`。
- 最大约束 `n = 160, budget = 160`：随机价格的链形树答案 `908`、本机耗时约 `0.009s`；星形树答案 `1141`、本机耗时约 `0.040s`。两者均正常完成。
