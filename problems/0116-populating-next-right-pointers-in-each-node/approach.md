# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

利用已建立的同层 `next` 指针逐层处理，不使用队列。对每个父节点，左孩子必然连接右孩子；若父节点有右侧邻居，右孩子还应连接该邻居的左孩子。完美二叉树保证每个非叶节点都有左右孩子，处理完一层后移到最左孩子。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 空树直接返回 `None`。
- 单节点树没有子层，保持其 `next` 为 `None`。
- 验证完美树 `[1,2,3,4,5,6,7]`：`2.next=3`，`4.next=5`，`5.next=6`，`6.next=7`，每层末尾为 `None`。
