## 算法与思路

按数字符号分别处理：

- `num < 0`：要让结果尽可能小，即让绝对值尽可能大。把所有数字按降序排列后加回负号。
- `num > 0`：要让结果尽可能小，应按升序排列。但首位不能为零，因此把排序后第一个非零数字换到首位，其余数字仍保持尽可能小的排列。
- `num = 0`：直接返回 `0`。

## 正确性

对于负数，符号固定时绝对值越大，整数值越小。按位比较可知把更大数字放在更高位能使绝对值最大，因此降序排列最优，零自然位于末尾且不会产生前导零。

对于正数，最高位对数值影响最大。合法最高位必须非零，所以选择所有数字中最小的非零数字最优。最高位确定后，剩余数字按升序放置能逐位取得最小值。算法从整体升序序列中把第一个非零数字换到首位，正好得到这一排列，因此结果最小。

## 复杂度

设十进制位数为 `d`：

- 时间复杂度：`O(d log d)`，主要来自排序。
- 空间复杂度：`O(d)`，用于保存数字字符。

## 边界条件与本地验证

- `num = 0`：避免查找不存在的非零数字，直接返回 `0`。
- 正数含多个零：把最小非零数字放在首位，所有零紧随其后。
- 负数含零：降序排列会把零放在低位。
- 本地验证覆盖题目样例 `310 -> 103`、`-7605 -> -7650`，并覆盖零、多零正数、多零负数和无需调整的单个数字。
