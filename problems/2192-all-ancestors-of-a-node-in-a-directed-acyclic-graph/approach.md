# 解题记录

## 思路

## 算法、正确性与复杂度

按拓扑排序处理 DAG，并为每个节点维护祖先集合。处理边 `u -> v` 时，将 `u` 及 `u` 的全部祖先并入 `v`；当 `v` 的入度归零时，其所有父节点都已处理，可安全入队。归纳可知处理每条入边后集合恰包含对应路径祖先，最终集合完整；排序后符合输出要求。若以集合并入时遍历的祖先元素总数记为 `A`，时间为 `O(n + edges.length + A)`，此外输出排序最坏为 `O(n² log n)`；祖先集合总空间最坏为 `O(n²)`，图与队列为 `O(n + edges.length)`。

## 边界与验证

- 入度为 0 的节点祖先为空。
- 多条路径到同一祖先由集合去重。
- 用题面两组样例、无边图和菱形依赖图断言验证。
