## 思路

## 算法

枚举每个格子作为菱形中心，并枚举不越界的半径。半径为 0 时菱形和就是中心格值；半径大于 0 时，沿上右、右下、下左、左上四条边各累加 `radius` 个格子，从而每个边界格恰好统计一次。维护最多三个不同和的集合：加入新和后若超过三个，移除其中最小值。最后按降序返回。

## 正确性

任意题目允许的菱形都有唯一中心和半径，枚举覆盖所有中心及不越界半径，因此不会遗漏。四条边按半开区间遍历，四个顶点分别只由一条边计入，恰好求得该菱形边界和。集合始终保留迄今为止三个最大的不同值，处理所有菱形后即为所求前三个不同菱形和。

## 复杂度

设行列数为 `m,n`，每个中心半径的边界计算为 `O(radius)`，总时间上界为 `O(mn·min(m,n)^2)`；题目中 `m,n<=100`。集合大小始终不超过 3，额外空间复杂度为 `O(1)`。

## 边界

单行或单列只有半径 0 的菱形；多个菱形和相同只保留一个值。
