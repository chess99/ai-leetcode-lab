# 解题记录

## 思路

## 算法、正确性与复杂度

从 `'z'` 向 `'a'` 贪心选择当前最大的剩余字符，一次最多追加 `repeatLimit` 个。若该字符仍有剩余，必须插入一个较小的可用字符作为分隔符；若不存在分隔符，则无法再合法延长。每一步都优先放入可行的最大字符，故其首个不同位置不小于任何其他可行构造，得到字典序最大结果。每个输出字符只追加一次，寻找较小分隔字符的指针也只向下移动，时间 `O(|s| + 26)`；计数表和指针为 `O(26)=O(1)`，返回字符串占 `O(|s|)` 空间。

## 边界与验证

- 仅一种字符时最多保留 `repeatLimit` 个。
- 剩余最大字符无分隔符时立即停止。
- 使用题面两组样例、全同字符和限制为 1 的断言验证。
