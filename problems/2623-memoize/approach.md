## 思路

用参数数组的 JSON 表示作为缓存键。包装函数调用时，若键不存在才执行原函数并保存结果；存在时直接返回缓存值。

## 复杂度

每次调用除参数序列化外，映射查询平均 `O(1)`；缓存空间与不同参数列表数成正比。

## 边界条件与本地验证

参数顺序被 JSON 数组保留，`[2, 3]` 与 `[3, 2]` 的缓存键不同。使用 `has` 而非真值判断，因此函数返回 `0` 等假值也可正确缓存。
