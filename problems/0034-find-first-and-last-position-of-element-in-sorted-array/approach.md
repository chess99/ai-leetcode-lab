# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

执行两次二分。第一次命中目标后继续向左收缩，记录最后一次命中的下标，即左边界；第二次命中后继续向右收缩，得到右边界。若目标不存在，两次都保留初始值 `-1`。

## 复杂度

- 时间复杂度：O(log n)，两次二分的常数倍。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 空数组直接返回 `[-1, -1]`。
- 目标只出现一次时两个边界相同。
- 目标位于数组两端或完全不存在都由同一二分逻辑覆盖。
- 验证：`[5,7,7,8,8,10], 8 -> [3,4]`、同数组查找 `6 -> [-1,-1]`、`[], 0 -> [-1,-1]`、`[2,2], 2 -> [0,1]`。
