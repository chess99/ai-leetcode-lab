## 思路

后序遍历为每个节点记录三种状态：自身有相机、已被子节点覆盖、尚未覆盖。若任一子节点未覆盖，当前节点必须放相机；若任一子节点有相机，当前节点已覆盖；否则把未覆盖需求交给父节点。最后单独处理根节点。使用显式栈生成后序处理顺序，避免退化树超过 Python 递归深度。

## 复杂度

每个节点访问一次，时间 `O(n)`；显式栈与状态表空间 `O(n)`。

## 边界条件与本地验证

空节点视为已覆盖，避免在叶节点放相机；空树需要 0 台；若根最终未覆盖，需补一台相机。以小树枚举所有相机子集验证最优值，并专项验证 1000 节点退化树不会触发递归错误。
