# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

用下标从左到右扫描：先跳过前导空格，再读取至多一个正负号，随后连续累积十进制数字。每次累积前根据目标上界检查 `value * 10 + digit` 是否会溢出；正数上界为 `2^31 - 1`，负数的绝对值上界为 `2^31`。一旦溢出即可直接返回对应的截断值。遇到非数字或字符串结束时返回已累积的值乘以符号。

## 复杂度

- 时间复杂度：O(n)，每个字符最多访问一次。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 空串、仅空格、首个有效字符不是数字或符号时返回 `0`。
- 只接受一个紧随空格后的符号；`"+-12"` 和 `"0-1"` 都会在非数字处停止。
- 连续前导零自然参与累积且不影响结果。
- 验证了普通输入、遇到字母停止、正负溢出截断：`"42" -> 42`、`"   -042" -> -42`、`"1337c0d3" -> 1337`、`"91283472332" -> 2147483647`、`"-91283472332" -> -2147483648`。
