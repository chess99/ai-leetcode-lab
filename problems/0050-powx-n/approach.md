## 思路

使用二进制快速幂。负指数先转换为底数的倒数和正指数。随后从指数的最低位开始：若该位为 1，就把当前底数乘入答案；每轮将底数平方并把指数右移一位。这样每个二进制位只处理一次。

## 复杂度

指数每轮减半，时间为 `O(log |n|)`；循环只使用常数个变量，额外空间为 `O(1)`。

## 边界条件与本地验证

- `n = 0` 时循环不执行，返回乘法单位元 `1.0`。
- 负指数通过先求倒数处理；题目保证零底数时指数为正，避免除以零。
- Python 整数可安全取反最小 32 位指数，不存在固定宽度溢出。
- 本地断言：`2.0^10 = 1024.0`、`2.1^3 = 9.261`、`2.0^-2 = 0.25`，以及任意非零底数的零次幂为 `1.0`。
