# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

动态规划只保留前两个状态。首位为零时无解；否则单字符前缀有一种解法。之后遍历到每个位置时，若当前数字非零，可接在所有前缀解码后作为一位编码；若前两位形成 `10` 到 `26`，还可作为两位编码并加上再前一状态。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 防御性处理空字符串并返回 0；题面正式输入长度至少为 1。
- `'0'` 不能独立解码，只有与前导 `1` 或 `2` 配对时有效。
- `'06'` 因前导零返回 0；`'10'` 只有一种解法。
- 验证：`"12" -> 2`、`"226" -> 3`、`"06" -> 0`、`"11106" -> 2`、`"10" -> 1`；随机数字串与记忆化递归 oracle 对拍 5000 组。
