# 2091. 从数组中移除最大值和最小值

## 思路

找到最小值与最大值的下标，并令 `left` 为两者中较小的下标、`right` 为较大的下标。删除两者只可能有三种最优形式：全部从左端删除，删除 `right + 1` 个；全部从右端删除，删除 `n - left` 个；或左端删到 `left`、右端删到 `right`，共 `left + 1 + n - right` 个。返回三者最小值。

### 正确性说明

若两端目标元素均从左端删除，必须删除至较靠右的目标位置；若均从右端删除，必须删除至较靠左的位置。若使用两端删除，左端最少须删至 `left`，右端最少须删至 `right`，多删任一端不会更优。所有可行删除方案都属于这三类之一，算法比较其最小次数，因此结果最优。

## 复杂度

查找最大、最小值各扫描一次，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## 边界条件与本地验证

- 数组只有一个元素时，它同时是最大值和最小值，答案为 1。
- 两个目标元素都靠近同一端时，单端删除会被选中。
- 两个目标元素分别靠近两端时，混合删除可能更少。
