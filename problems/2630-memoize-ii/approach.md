# 解题记录
- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium
## 思路
建立一棵以参数为边的 Map 字典树：一层对应一个参数，Map 直接按 JavaScript 的值或对象身份比较键。走完整个参数序列后，终点节点缓存首次调用结果，并用独立布尔位区分“尚未计算”和“结果恰为 undefined”。这样不同空对象不会冲突，重复传入同一个对象则会命中。
## 复杂度
单次调用时间 O(k)，k 为参数个数；空间与所有不同参数前缀总数成正比。
## 边界条件与本地验证
验证了原始值参数、结果为 undefined、零参数、三个不同空对象不命中，以及同一对象反复传入只调用一次。Node 行为回归通过。
