# 2170. 使数组变成交替数组的最少操作数

## 算法

分别统计偶数下标和奇数下标的值频次，并各自保留出现次数最多的两个值。最终数组的偶数位必须统一为某个值，奇数位必须统一为另一个不同值。若两侧最高频值不同，直接保留它们；若相同，则比较“偶数位第一、奇数位第二”和“偶数位第二、奇数位第一”两种搭配，选择保留元素数更多的一种。

## 正确性说明

固定偶数位和奇数位的目标值后，所有与目标值不同的位置都必须修改，保留该值出现次数最多的选择显然最优。当两侧最高频值不同，它们可同时使用并分别达到最优保留数。当两侧最高频值相同时，两侧不能都选它；至少一侧必须改用次高频值，只有两种上述搭配，算法取其中修改数较少者。因此得到全局最少操作数。

## 复杂度分析

统计频次和取前两名共耗时 `O(n)`，哈希表空间复杂度为 `O(n)`。

## 边界情况

- 长度为 1 时，奇数下标侧为空，答案为 0。
- 只有一种数值时，需要修改其中一类下标。
- 次高频值不存在时按频次 0 处理，仍能正确选择一个新正整数。
