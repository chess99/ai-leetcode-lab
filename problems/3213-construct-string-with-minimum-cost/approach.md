## 思路

先把所有单词建成 Aho-Corasick 自动机；重复单词只保留最低成本。失败指针让扫描 `target` 时能在线找到所有以当前位置结尾的单词。

令 `dp[i]` 为构造 `target[:i]` 的最低成本。若长度为 `L`、成本为 `C` 的单词在 `i` 结尾，就用 `dp[i-L] + C` 更新 `dp[i]`。最终状态不可达时返回 -1。

## 复杂度

设目标长度为 `T`，单词总长度为 `S`，匹配总数为 `Z`。时间复杂度为 `O(T + S + Z)`，空间复杂度为 `O(T + S)`。

## 边界条件与本地验证

重复单词、某个前缀不可构造、多个后缀单词同时匹配均已覆盖；不可达状态使用足够大的值隔离。本地以随机小字母串和词表，与逐位置尝试全部单词的朴素 DP 对拍一致。
