## 思路
把 `k` 条线段按从左到右的顺序记为端点
`l1 < r1 <= l2 < r2 <= ... <= lk < rk`。共享端点处的等号会妨碍直接计数，于是把第 `i` 条线段的两个端点都向右平移 `i-1`，得到从 `0` 到 `n+k-2` 中严格递增的 `2k` 个位置。这个变换可逆，因此答案是从 `n+k-1` 个位置中选择 `2k` 个位置，即 `C(n+k-1, 2k)`，最后对 `10^9+7` 取模。
## 正确性
合法线段组内，每条线段的左端点严格小于右端点，相邻线段允许共享端点。按线段序号做平移后，原来的严格不等号仍然严格，共享端点也被拉开为严格递增，因此恰好得到一个大小为 `2k` 的位置子集。反向减去对应偏移即可唯一恢复原端点，并保持 `r_i <= l_(i+1)`，所以该变换是一一对应。故组合数精确计数所有且仅有合法线段组。
## 复杂度
`math.comb` 计算该组合数需要 `O(k)` 次大整数乘除；若按题目范围把整数运算视为常数，时间为 `O(k)`，除结果整数外额外空间为 `O(1)`。
## 边界条件与本地验证
- 覆盖 `k=1`、共享端点和模数取模。
