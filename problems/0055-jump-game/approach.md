# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

从左到右维护当前能到达的最远下标 `furthest`。若扫描位置已超过它，说明该位置不可达，直接失败；否则用当前位置可跳距离扩展最远可达位置。当其覆盖最后一个下标时立即成功。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 单元素数组初始就在终点。
- 中间的零只有在最远可达位置不能越过它时才会阻塞。
- 验证：`[2,3,1,1,4] -> True`、`[3,2,1,0,4] -> False`、`[0] -> True`、`[2,0,0] -> True`。
