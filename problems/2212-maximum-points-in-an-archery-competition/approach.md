# 2212. 射箭比赛中的最大得分

## 算法

共有 12 个计分区，枚举每个区是否由 Bob 获胜的所有 `2^12` 个子集。若选择区 `i`，必须投入 `aliceArrows[i] + 1` 支箭，得到 `i` 分。对每个子集计算所需箭数和得分；在不超过 `numArrows` 的子集中保留最高分方案。最后将未使用的箭全部放在 0 分区。

## 正确性说明

Bob 若要赢得区 `i`，最少且最优的投入正是 `aliceArrows[i] + 1` 支箭；多投入不会增加该区分数。因此任何最优方案完全由“赢哪些区”这一子集决定。算法枚举全部子集，并只保留箭数合法的方案，所以一定访问到最优方案对应的子集；选出的最高分子集即为全局最优。剩余箭放在 0 分区不改变得分且保证箭数总和正确。

## 复杂度分析

枚举 `2^12` 个子集，每个检查 12 个区，时间复杂度为 `O(12 * 2^12)`，空间复杂度为 `O(1)`（输出数组除外）。

## 边界情况

- 无法赢得任何正分区时，所有箭可放在 0 分区。
- 多种方案同分时，任意一种均合法。
- Alice 在某区为 0 支箭时，Bob 仍需要 1 支箭才能得到该区分数。
