# 解题记录

## 算法

枚举实际出现的数字集合。数字 d 一旦出现就必须出现 d 次；回文中至多有一种数字出现奇数次，因此集合中至多包含一个奇数数字。回文由“前半段的多重集排列 + 中心数字 + 前半段逆序”唯一决定。

对长度大于 n 的集合，取升序前半段即可得到该集合最小回文。长度相同时，先检查 n 的前半段能否由该多重集精确组成；再通过从右向左保留最长相等前缀的方式，构造严格大于目标前半段的最小多重集排列。

## 正确性

枚举覆盖了所有可能的数字集合；奇数计数条件是多重集能够排列成回文的充要条件。固定集合后，中心与前半段计数均唯一，且回文大小随前半段字典序单调。算法分别取得等前半段时可能超过 n 的候选，以及严格大于目标前半段的最小排列，因此得到该集合中最小的合法上界。对全部集合取最小值即为全局答案。

## 复杂度

只枚举 2^9 个数字集合。设候选长度为 L，单个集合的构造为 O(9L)，总时间可视为常数，额外空间为 O(L)。
