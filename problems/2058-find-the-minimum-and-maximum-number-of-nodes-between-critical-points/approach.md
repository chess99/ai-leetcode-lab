# 2058. 找出临界点之间的最小和最大距离

## 思路

用相邻三个节点从左到右扫描。中间节点严格大于两侧节点或严格小于两侧节点时，它是临界点。记录第一个临界点和上一个临界点下标；每发现一个新临界点，用它与上一个临界点的距离更新最小值。最后一个临界点与第一个临界点的距离即为最大值。

### 正确性说明

每个非首尾节点都被检查一次，判断条件与临界点定义一致，因此不会遗漏或误判临界点。最小距离必然发生在相邻临界点之间，算法逐对比较得到最小值；最大距离必然由最左和最右临界点组成，算法保留这两个位置后能得到最大值。少于两个临界点时不存在有效距离，返回 `[-1, -1]`。

## 复杂度

链表只遍历一次，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## 边界条件与本地验证

- 长度小于 3 的链表没有临界点。
- 相邻值相等不构成极大值或极小值。
- 只有一个临界点时返回 `[-1, -1]`。
