# 解题记录

## 算法

枚举分给 B 的元素集合。其余元素的总异或记为 T；若 A 的异或为 x，则 C 的异或为 `T xor x`，并有 `x + (T xor x) = T + 2 * (x & ~T)`。因此只需在剩余元素的异或线性空间中，最大化被 `~T` 保留的位。

把每个剩余元素先与 `~T` 相与，再插入异或线性基，贪心求最大可达异或。B 的按位与和子集异或用最低位递推预计算。

## 正确性

固定 B 后，A 与 C 是剩余元素的一个二分，选择 A 即唯一确定 C。恒等式表明两组异或和仅由 T 与 `x & ~T` 决定。所有 A 的异或恰为剩余元素张成的异或线性空间，而线性映射 `x -> x & ~T` 的像由映射后的生成元张成；线性基贪心可得到该空间最大异或。枚举所有 B 后必包含全局最优划分，因此答案正确。

## 复杂度

设 n 为数组长度、w 为数值位数。时间复杂度为 O(2^n * n * w)，空间复杂度为 O(2^n + w)。
