## 思路

后序处理每个节点：左、右子树分别返回是否找到 `p` 或 `q`；若两侧都有结果，当前节点就是最近公共祖先，否则把非空的一侧向上传递。节点本身为 `p` 或 `q` 时可直接向上传递，因为题目保证两者都存在。

使用显式栈保存节点、处理阶段和左子树结果，等价模拟递归后序。这样不需要父指针映射，并且退化为很深的单链树时也不会触发 Python 递归上限。

## 复杂度

时间复杂度为 O(n)，显式栈空间为 O(h)，其中 h 是树高。

## 边界条件与本地验证

检查两个节点位于不同子树、一个节点是另一个的祖先，以及最近公共祖先为根的情况；另用超过 Python 默认递归上限的单链树验证节点身份和深树安全性。
