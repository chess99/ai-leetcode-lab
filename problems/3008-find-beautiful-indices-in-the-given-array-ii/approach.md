# 解题记录
- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium
## 思路
分别对 `pattern + '#' + s` 计算 KMP 前缀函数，线性收集 `a`、`b` 的全部出现位置。对每个 `a` 的位置，在有序的 `b` 位置表中二分第一个不小于 `i-k` 的位置，检查它是否不超过 `i+k`。
## 复杂度
时间 `O(n+|a|+|b|+A log B)`，其中 `A/B` 为两个模式的出现次数；空间 `O(n+|a|+|b|)`。满足 `n<=5*10^5` 的上限。
## 边界条件与本地验证
允许距离恰好等于 `k`，模式可重叠出现或无任何出现。题面样例及随机短串逐位置匹配 oracle 通过。
