# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

先用快慢指针找到前半段尾部并断开链表，再原地反转后半段。最后交替从前半段和反转后的后半段取节点连接，得到 `L0 → Ln → L1 → Ln-1 ...` 的顺序。以 `fast = head.next` 起步使前半段在偶数长度时不会比后半段短。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 空链表、单节点和双节点均可安全处理。
- 先断开前半段再反转，防止合并后形成环。
- 验证：`[1,2,3,4] -> [1,4,2,3]`、`[1,2,3,4,5] -> [1,5,2,4,3]`、`[1,2] -> [1,2]`。
