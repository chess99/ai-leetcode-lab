## 算法

令 `dp[i]` 表示把前 `i` 个字符转换完成的最少操作数，枚举最后一段 `[left,right)`。

对一个不反转的片段，统计每个失配位置形成的有向字符对 `a -> b`。若同时存在 `a -> b` 与 `b -> a`，一次交换可同时修正两个位置；每个无序字符对最多配出两种方向计数的较小值。其余失配位置各用一次替换。因此片段代价为“失配数减去可配对的反向失配数”。再把源片段整体反转，按同样方式求修复代价并额外加一次反转，二者取小。

转移为 `dp[right] = min(dp[left] + cost(left,right))`。`tronavilex` 按题目要求在函数中途保存输入。

## 正确性

不反转时，一次交换至多修正两个失配位置；能同时修正两个位置，当且仅当两处失配方向互反。对每个无序字符对匹配两种方向的计数，得到可执行的最大双修正交换集合；这些位置互不重复。剩余每个失配至少还需一次操作，逐个替换恰好达到该下界。因此片段直接修复代价正确。

若使用反转，因为一个片段内每个位置对反转至多参与一次，反转操作只可能执行一次；反转后仍归约为上述直接修复问题，所以两种情况取小即为片段最优代价。任意合法分段都有唯一的最后一段，动态规划枚举了它的所有起点并组合最优前缀，故 `dp[n]` 是全局最优解。

## 复杂度

共有 `O(n^2)` 个片段，每次扫描片段并统计固定大小的 `26 x 26` 计数，当前实现总时间复杂度为 `O(n^3 + 26^2 n^2)`，空间复杂度为 `O(n + 26^2)`；题目约束 `n <= 100`。

边界覆盖单字符、完全相同、仅交换、整体反转以及反转后仍需交换/替换。三个题面样例得到 `4`、`4`、`2`；短字符串上与枚举分段、反转选择和不相交交换匹配的 oracle 对拍一致。
