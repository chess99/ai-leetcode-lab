# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-sol
- 推理档位：medium
- Profile：sol-medium

## 算法

设 `dp[i]` 为前 `i` 个字符完成转换的最少操作数，枚举最后一段 `[j,i)`。一段内部先考虑不反转：统计所有失配位置形成的有向字符对 `a -> b`。一对方向相反的失配 `a -> b`、`b -> a` 可以用一次交换同时修正；其他失配各用一次替换。因此代价是失配数减去所有无序字符对可配对的数量。再对源段整体反转后做同样计算，并额外加一次反转操作，两者取小值。

不同字符对使用的失配位置互不重叠，同一个有向字符对也只会与其反向配对，所以满足每个位置在每类操作中最多使用一次的限制。

## 正确性

固定一段且不反转时，一次交换至多同时修正两个位置；能同时修正两个位置当且仅当两个失配方向互反。对每个无序字符对取两种方向计数的较小值，恰好得到可执行的最多双修正交换数，剩余位置逐个替换即达到下界。反转操作若使用，只可能对整段使用一次，之后问题归约为同一个“不反转”子问题。最后，任意合法分割都有唯一的最后一段，动态规划枚举了它并取最小值，故得到全局最优解。

## 复杂度

共有 `O(n^2)` 个片段，每次计算代价耗时 `O(n + 26^2)`，总时间 `O(n^3 + 26^2 n^2)`，空间 `O(n + 26^2)`；`n <= 100`。

## 边界条件与本地验证

覆盖单字符段、完全相同字符串、仅交换、整段反转以及反转后仍需交换/替换的情况；三个题面样例输出分别为 `4、4、2`。另以短字符串完整枚举分割、反转、互不相交交换和替换的 oracle 对拍。
