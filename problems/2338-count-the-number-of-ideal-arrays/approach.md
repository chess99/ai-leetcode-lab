# 解题记录

## 思路

先统计长度为 `len` 的严格整除链数量：从较小末值向它的倍数转移。任意理想数组压缩相邻相等段后就是严格链；长度为 len 的链扩展到 n 个位置，相等段分界有 `C(n-1,len-1)` 种。由于每次严格增长至少翻倍且最大值不超过 10⁴，链长至多 14。

## 复杂度

时间约 `O(maxValue*log maxValue*14+n*14)`，空间 `O(maxValue*14+n*14)`。

## 边界条件与本地验证

长度 1 的链贡献 maxValue；所有组合均取模。题面样例得到 `10、11`；小 `n/maxValue` 枚举全部数组对拍，上限 `10000*10000` 烟测约 0.17 秒。
