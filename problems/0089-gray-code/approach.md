## 思路

第 `i` 个二进制反射格雷码可直接由公式 `i ^ (i >> 1)` 得到。依次计算从 0 到 `2^n - 1` 的值，自动得到以 0 开头、相邻（包括首尾）仅一位不同的序列。

## 复杂度

- 时间复杂度：O(2^n)。
- 空间复杂度：O(2^n)，用于返回序列。

## 边界条件与本地验证

- `n = 1` 得到 `[0, 1]`。
- 输出长度恰为 `2^n`，每个值都在合法范围且不重复。
- 验证：`2 -> [0,1,3,2]`、`1 -> [0,1]`，并检查相邻值异或后均为单一置位比特。
