# 解题思路

## 算法

扫描每个连续同色段。长度为 `L` 的 `A` 段中，Alice 最多可删除 `L - 2` 个（仅在 `L >= 3` 时为正）；删除它们不会给 Bob 创造 `B` 的可删位置。对 `B` 段同理统计 Bob 的可删数。比较两个总数：Alice 先手，只有自己的可操作次数严格更多时才能获胜。

## 正确性证明

可删除的棋子必须处于长度至少 3 的同色连续段内部。一个长度为 `L` 的同色段无论按何种顺序删除，都会在长度降到 2 时停止，恰可删除 `L - 2` 个；删除不会跨越异色段，因此不会影响另一方的可操作数。故两人的总可操作次数可独立预先计算。双方每回合只能消耗自己的一个操作，Alice 先手时当且仅当 `A` 的操作数多于 `B` 的操作数才能让 Bob先无棋可删，算法判定正确。

## 复杂度分析

一次扫描字符串，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## 边界情况

- 连续段长度小于 3 时不贡献操作。
- 全部为同一种颜色时由该颜色的段长度直接决定。
- 没有任何可删除棋子时 Alice 首回合即失败。
