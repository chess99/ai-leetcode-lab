## 思路

统计每个数字的出现次数。回文数的左右两半完全对称，因此从 9 到 0 依次将每个数字的 `count // 2` 个副本加入左半部分；从大到小构造可以使最高位尽可能大。左半部分尚为空时跳过 0，避免产生前导 0。中间位选择出现次数为奇数的最大数字，最后拼接“左半 + 中间 + 左半反转”。

若无法构造非零的左右半部分，答案只能是最大奇数次数数字，或全为 0 时的单个 `"0"`。

## 复杂度

统计和构造均线性扫描输入，时间复杂度为 `O(n)`；计数器和结果字符串以外只使用常数个数字桶，额外空间复杂度为 `O(n)`（结果不计则为 `O(1)`）。

## 边界条件与本地验证

- 0 不能作为左半部分的第一位，但可以在已有非零首位后成对加入。
- 不必使用全部数字，中间位只保留最大的一个奇数剩余数字。
- 已验证题面样例：`"444947137"` 返回 `"7449447"`，`"00009"` 返回 `"9"`。
- 已验证边界：`"0000"` 返回 `"0"`，`"010"` 返回 `"1"`，`"1001"` 返回 `"1001"`。
