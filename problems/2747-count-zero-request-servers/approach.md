# 解题记录

- Profile：terra-medium
- 轮次：1

## 思路

按时间排序日志和查询，按查询时间递增维护闭区间 `[time-x, time]` 的滑动窗口。右指针加入不晚于当前时间的日志，左指针移除早于下界的日志；哈希表记录每台服务器在窗口中的日志数，另维护收到至少一次请求的服务器数量。答案即总服务器数减去该数量。

## 复杂度

排序耗时 `O(L log L + Q log Q)`，双指针扫描 `O(L + Q)`；哈希表和答案空间 `O(n + Q)`。

## 边界条件与本地验证

时间区间两端均包含，故只移除严格早于 `time-x` 的日志；同一服务器有多条日志时，计数归零后才变为未活跃；答案按原查询顺序回填。
