## 根因

原递归以 `(i, carry)` 记忆化。虽然每个状态只有三个转移，但第 `i` 层可能有 `O(i)` 种不同的 `carry`，所有层累计会保存 `O(n^2)` 个缓存条目；原文所写的 `O(n)` 时间、空间并不成立。Python 字典、元组和递归缓存的常数开销较大，因此达到 `n = 1000` 时触发内存超限。

## 算法：逐层滚动动态规划

令 `i` 是下两个尚未加入处理窗口的元素中的第一个下标。此时：

- 下标小于 `i` 的元素中恰好只剩一个；
- `dp[j]` 表示这个剩余元素是 `nums[j]` 时，此前操作的最小成本。

初始时 `i = 1`，只有 `nums[0]` 被保留，故 `dp = [0]`。

当 `nums[i]` 和 `nums[i + 1]` 都存在时，当前前三个元素是保留的 `nums[j]`、`nums[i]`、`nums[i + 1]`。枚举本次留下谁：

1. 留下 `nums[j]`：删除两个新元素，所有旧状态都增加 `max(nums[i], nums[i + 1])`；
2. 留下 `nums[i]`：从所有旧状态取 `dp[j] + max(nums[j], nums[i + 1])` 的最小值；
3. 留下 `nums[i + 1]`：从所有旧状态取 `dp[j] + max(nums[j], nums[i])` 的最小值。

更新后令 `i += 2`。滚动数组只保留当前层，不再保存已经无用的历史层。

循环结束后：

- 若还剩一个未处理元素 `nums[i]`，将它与每种可能的保留元素一次性删除，取 `dp[j] + max(nums[j], nums[i])` 的最小值；
- 否则只剩保留元素，取 `dp[j] + nums[j]` 的最小值。

代码中按题面要求，用变量 `xantreloqu` 保存函数输入的中间值。

## 正确性证明

用循环不变式证明：每轮开始时，对每个 `0 <= j < i`，`dp[j]` 恰为已经处理下标 `[0, i)`、其中只保留 `nums[j]` 的最小成本。

初始时 `i = 1`，尚未执行操作，`[0, 1)` 中只剩 `nums[0]`，成本为 0，不变式成立。

假设某轮开始时不变式成立。加入 `nums[i]`、`nums[i + 1]` 后，当前恰有三个候选元素。合法操作必须删除其中两个，因此留下的元素只可能是 `nums[j]`、`nums[i]` 或 `nums[i + 1]`。转移分别完整枚举这三类选择，并对所有可能的旧保留元素 `j` 取最小值；每项所加的费用正是被删除两元素的最大值。因此，新 `dp` 对每种新保留元素都取得且只取得合法方案中的最小成本，不变式对 `i + 2` 成立。

循环结束时，数组只剩一个保留元素，或该元素加一个尚未处理元素。题目规定少于三个元素时必须一次性全部删除；终止式枚举所有保留元素并加上这次操作的准确成本。由不变式，所得最小值就是删除全部元素的全局最小成本。

## 复杂度

第 `i` 层有 `i` 个状态，每轮扫描当前状态常数次，所有层状态数之和为 `O(n^2)`；时间复杂度为 `O(n^2)`。滚动数组最多保存 `n` 个整数，空间复杂度为 `O(n)`。

## 边界条件与本地验证

- `n = 1`：直接支付唯一元素的值；
- `n = 2`：一次删除两个元素，支付二者最大值；
- 奇数长度：最后只剩一个保留元素；
- 偶数长度：最后剩保留元素和一个未处理元素；
- 重复值不会合并下标状态，也不影响转移正确性；
- 最大长度下不使用递归，且只保留线性状态。

本地验证包含题面示例、长度 1/2 的边界、与穷举 oracle 的随机差分测试，以及 `n = 1000` 压力测试。
