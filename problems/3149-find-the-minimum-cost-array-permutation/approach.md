## 思路

分数是环的代价，循环旋转不改变分数，因此字典序最小解一定从 0 开始。记忆化 `dp(mask,last)`，枚举下一未选下标并加入 `abs(last-nums[next])`；全部选择后加入回到 0 的闭环代价。重建时按下标从小到大选择第一个保持最优代价的下一项，保证字典序最小。

## 复杂度

时间复杂度为 `O(n^2 2^n)`，空间复杂度为 `O(n2^n)`。

## 边界条件与本地验证

闭环代价不能遗漏；固定首项为 0 不损失任何最优环。已核对 2 组样例，并对 `n<=8` 的随机排列枚举所有以 0 开头的排列作 oracle。
