# 解题记录

- Profile：terra-medium

## 思路

在普通二分中，比较左端、中点和目标值。由于元素互异，左右两半至少有一半连续有序：若左半有序，就判断目标是否落在该值域内；否则目标只能在另一半。右半有序时作对称判断。每轮排除一半区间。

## 复杂度

- 时间复杂度：O(log n)。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 数组未旋转时退化为普通二分。
- 只有一个元素且不匹配时正确返回 `-1`。
- 题目保证元素互异，因而可用 `<=` 唯一确定有序半区。
- 验证：`[4,5,6,7,0,1,2], 0 -> 4`、同数组查找 `3 -> -1`、`[1], 0 -> -1`、`[1,3], 3 -> 1`。
