## 思路

terra-medium 的固定末尾枢轴二路 Quickselect 在大量重复元素下会严重退化：例如十万个相同元素且 `k = 50000` 时，每轮只能排除一个位置。

根据题目约束，元素只会落在 `[-10000, 10000]`。建立长度为 20001 的频次数组，统计每个值出现的次数；随后从最大值向最小值扫描，不断从 `k` 中扣除当前值的出现次数。第一次使剩余名次不大于 0 的值，就是第 k 大元素。重复元素自然按出现次数占据多个名次。

## 复杂度

设值域大小为 `R = 20001`。时间复杂度为 `O(n + R)`，在本题固定值域下为 `O(n)`；空间复杂度为 `O(R)`，在本题约束下为常数额外空间。

## 边界条件与本地验证

- 重复元素按位置而非不同值计数。
- 同时支持值域两端 `-10000` 和 `10000`。
- 本地验证覆盖两个题目示例、单元素、混合正负边界，以及十万个相同元素且 `k = 50000` 的原 TLE 场景。
