# 2054. 两个最好的不重叠活动

## 算法

按开始时间升序排序，并用最小堆保存此前开始的活动，堆元素为 `(结束时间, 价值)`。扫描当前活动时，弹出所有结束时间严格小于当前开始时间的活动，并维护这些已结束活动的最大价值 `best_completed`。当前活动可单独选择，或与该最大价值活动组合；随后将当前活动加入堆。

## 正确性说明

被弹出的活动恰好满足 `end < start`，因此都能与当前活动组合；`best_completed` 保存其中价值最大者。仍留在堆中的活动与当前活动重叠，不能组合。故对每个当前活动，算法都求得以它为后一项的最优选择；遍历全部活动后也覆盖单选活动，答案最优。

## 复杂度分析

排序和堆操作总时间复杂度为 `O(n log n)`，堆空间复杂度为 `O(n)`。

## 边界情况

- 只有一个活动时，返回该活动价值。
- 活动端点包含在区间内，`end == start` 时仍重叠。
- 所有活动重叠时，返回价值最大的单个活动。
