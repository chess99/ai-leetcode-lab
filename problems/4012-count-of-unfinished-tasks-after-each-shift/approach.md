# 解题记录

## 思路

按题面要求用 `drelvanito` 保存输入。用 `progress` 表示当前这一轮从任务 0 开始已经完成的
总工作量，并预处理任务时长前缀和。对于一个班次，如果其时长不小于当前轮剩余总工作量，
所有任务完成，丢弃多余时间并把 `progress` 重置为 0；否则直接累加班次时长。

未完成整轮时，在任务前缀和中二分不超过 `progress` 的边界，得到已经完全完成的任务数；
当前部分处理的任务仍计为未完成。

## 复杂度

预处理 `O(n)`，每个班次二分 `O(log n)`，总时间 `O(n+q log n)`，空间 `O(n)`。

## 边界条件与本地验证

班次恰好完成剩余工作时答案为 0 并重置；完成整轮后的剩余班次时间不能用于下一轮。
`bisect_right` 正确把恰好到达前缀边界的任务计为已完成。验证三个题面样例，并与逐单位/
逐任务模拟的小规模随机用例对拍，包括每个班次都能完成整轮的性能反例。
