# 解题记录

原始创建者：`terra-medium`（`gpt-5.6-terra / medium`）。

本次由 `sol-medium`（`gpt-5.6-sol / medium`）接手修复。旧实现只检查
`nums1[i]` 是否能被 `nums2[j]` 整除，遗漏了题目要求的乘数 `k`。

## 思路

枚举所有下标对 `(i, j)`。令 `divisor = nums2[j] * k`，当且仅当
`nums1[i] % divisor == 0` 时，该下标对是优质数对，将答案加一。

题目保证数组元素和 `k` 都是正整数，因此除数始终非零。

## 正确性证明

算法恰好枚举一次所有合法下标对 `(i, j)`。

- 若算法计入 `(i, j)`，则余数 `nums1[i] % (nums2[j] * k)` 为零，所以
  `nums1[i]` 可以除尽 `nums2[j] * k`，该数对按定义是优质数对。
- 若 `(i, j)` 是优质数对，则 `nums1[i]` 可以除尽 `nums2[j] * k`，对应余数
  必为零；算法枚举到它时一定会将其计入。

因此算法计入的数对与全部优质数对完全一致，返回值正确。

## 复杂度

设两个数组长度分别为 `n`、`m`。时间复杂度为 `O(nm)`，额外空间复杂度为
`O(1)`。

## 边界条件与本地验证

- 回归例：`nums1 = [1,2,4,12]`、`nums2 = [2,4]`、`k = 3`，结果为 `2`。
- 样例 1：`nums1 = [1,3,4]`、`nums2 = [1,3,4]`、`k = 1`，结果为 `5`。
- 覆盖无优质数对、重复元素、所有数对都优质，以及长度为 1 的数组。
- 使用独立的朴素判定 oracle 对拍：穷举长度 1 至 3、元素值 1 至 5、
  `k` 取 1 至 5 的 120,125 组输入，另验证 10,000 组固定种子的随机输入，
  结果全部一致。
- 最大约束 `n = m = 50` 时仅检查 `2500` 个数对；全命中用例返回 `2500`。
