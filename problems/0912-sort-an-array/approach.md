# 解题记录

- AI 客户端：Codex Desktop

- 推理档位：medium
- Profile：terra-medium

## 思路

手写原地堆排序。先从最后一个非叶节点开始下沉，建立最大堆；随后反复把堆顶最大值交换到未排序区间末尾，并缩小堆、恢复最大堆性质。未使用 `sorted()`、`.sort()` 或其他内建排序函数。

## 复杂度

建堆为 `O(n)`，逐个取出最大值为 `O(n log n)`，总时间 `O(n log n)`；原地交换，额外空间 `O(1)`。

## 边界条件与本地验证

- 覆盖单元素、已排序、逆序、重复值、负数和最大规模随机数组；与独立计数 oracle 对拍，并做禁用排序 API 静态检查。
