# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

长度 `n-1` 的相邻位置中选出恰好 `k` 个保持相同，有 `C(n-1,k)` 种；首项有 `m` 种，剩余每个“不相同”位置均有 `m-1` 种。因此答案是 `m * C(n-1,k) * (m-1)^(n-1-k)`。

## 复杂度

预处理阶乘后时间 `O(n + log MOD)`，空间 `O(n)`。

## 边界条件与本地验证

覆盖 `k=0`、`k=n-1` 和 `m=1`。已对小 `n,m,k` 枚举全部数组对拍。
