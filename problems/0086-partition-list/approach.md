# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

维护“小于 x”和“大于等于 x”两条链表，各自使用虚拟头和尾指针。遍历原链表时先断开当前节点，再按值追加到对应链表，因而保持每个分区内的原始相对顺序。最后把小分区尾部接到大分区头部。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)，仅使用常数个指针。

## 边界条件与本地验证

- 使用延迟类型注解，已通过 importlib 独立加载；测试时构造本地 `ListNode` 并实际调用。
- 任一分区为空时，虚拟头能安全地完成连接。
- 遍历时断开 `next`，防止保留旧连接形成错误链路。
- 验证：`[1,4,3,2,5,2], 3 -> [1,2,2,4,3,5]`、`[2,1], 2 -> [1,2]`、`[1,1], 3 -> [1,1]`。
