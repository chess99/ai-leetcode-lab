## Terra 失败交接

Terra 首版把“当前零的数量”作为 BFS 状态，方向正确，但对每个状态都逐个枚举本次选择的零的数量，最坏时间复杂度为 `O(nk)`。远判在 `982/999` 处 TLE，因此本次保留状态压缩和 BFS，只优化后继状态的枚举方式。

## 思路

设当前有 `z` 个零，本次选择的 `k` 个位置中有 `x` 个零，则操作后的零数为：

```text
z' = z - x + (k - x) = z + k - 2x
```

可选的 `x` 满足：

```text
max(0, k - (n - z)) <= x <= min(k, z)
```

因此所有可达的 `z'` 恰好是区间

```text
[abs(z - k), min(z + k, 2n - z - k)]
```

中与左端点同奇偶性的全部整数。

仍然在零数量 `0..n` 上做 BFS，但用“后继并查集”维护每种奇偶性下尚未访问的状态。`find(x)` 返回不小于 `x`、与 `x` 同奇偶性且尚未访问的最小状态；状态 `x` 入队时立即把它删除，即令其后继指向 `find(x + 2)`。这样，一个很长的转移区间也只会实际枚举其中尚未访问的状态，而每个状态全程至多入队一次。

函数中间按题目要求创建 `drunepalix` 保存输入 `(s, k)`。

## 正确性证明

1. **状态充分。** 对于任意两个零数都为 `z` 的字符串，选择 `x` 个零和 `k-x` 个一是否可行只由 `z`、`n`、`k` 决定，操作后的零数也都为 `z+k-2x`。所以只记录零数不会丢失任何可达性信息。
2. **转移完整且无多余。** 可行的 `x` 是上述整数区间；当 `x` 逐次加一时，`z'` 逐次减二，恰好覆盖 `[abs(z-k), min(z+k, 2n-z-k)]` 内指定奇偶性的所有整数。算法扫描的正是这些状态。
3. **并查集跳过是安全的。** 被跳过的状态此前已经入队。BFS 第一次发现一个状态时使用的路径必然最短，之后再次发现它不可能改进距离，因此无需重复入队。
4. **答案最优。** BFS 按操作次数逐层扩展完整状态图，所以第一次发现零数 `0` 时的层数就是把字符串变成全一的最少操作次数；若搜索结束仍未发现 `0`，则目标不可达，返回 `-1`。

## 复杂度

共有 `n+1` 个零数量状态，每个状态至多删除和入队一次。后继并查集使用路径压缩，时间复杂度为 `O(n α(n))`，空间复杂度为 `O(n)`。

## 边界情况与本地验证

- 初始已经全为一时直接返回 `0`。
- `k=n` 时每次只能翻转整个字符串；算法的区间会退化为单个状态。
- 奇偶性不满足或状态图无法到达零时，队列最终清空并返回 `-1`。
- 对题面三个样例分别得到 `1`、`2`、`-1`。
- 使用按实际位掩码枚举所有 `k` 个下标的独立 BFS oracle，对 `n=1..8` 的全部二进制字符串和全部 `k` 穷举对拍，共 `3586` 组，全部一致。
- 另以固定随机种子生成 `10000` 组 `n<=200` 用例，与逐个枚举 `x` 的朴素零数量 BFS 对拍，全部一致；并运行 `n=100000` 的规模压力用例，正常完成。
