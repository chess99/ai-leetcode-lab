# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

先按起点排序。遍历每个区间：若起点大于已合并最后区间的终点，则不存在重叠，直接加入；否则两者重叠或相接，只需把最后区间终点扩展为两个终点的较大值。

## 复杂度

- 时间复杂度：O(n log n)，由排序主导。
- 空间复杂度：O(n)，用于合并后的结果。

## 边界条件与本地验证

- 相接区间如 `[1,4]` 和 `[4,5]` 视为可合并。
- 无重叠区间保持排序后的顺序。
- 验证：`[[1,3],[2,6],[8,10],[15,18]] -> [[1,6],[8,10],[15,18]]`、`[[1,4],[4,5]] -> [[1,5]]`、`[[4,7],[1,4]] -> [[1,7]]`。
