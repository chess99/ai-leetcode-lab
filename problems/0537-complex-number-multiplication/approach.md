## 思路

移除结尾的 `i` 后按唯一的分隔符 `+` 拆出实部和虚部；虚部为负数时字符串中的 `+-` 会被 `int` 正确解析。若两个复数分别为 `(a + bi)`、`(c + di)`，乘积为 `(ac - bd) + (ad + bc)i`，按题目格式拼接返回。

## 复杂度

设两个输入串总长度为 `n`。解析和格式化的时间复杂度为 `O(n)`，除输出外额外空间为 `O(n)`。

## 边界条件与本地验证

- 虚部为负数时输入格式如 `1+-1i`。
- 实部或虚部为 0 时仍需保留 `+` 与 `i`。
- 验证了 `"1+1i" * "1+1i" -> "0+2i"`、`"1+-1i" * "1+-1i" -> "0+-2i"` 与 `"0+2i" * "3+0i" -> "0+6i"`。
