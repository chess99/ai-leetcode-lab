## 思路

一个子数组可被成对清零，当且仅当每一位的 `1` 总数为偶数，也就是该子数组所有元素的异或值为零。令 `prefix` 为前缀异或；两个相同的前缀异或之间的子数组异或为零。扫描时用哈希表记录每个前缀异或此前出现次数并累加。

## 复杂度

时间复杂度 `O(n)`，哈希表空间复杂度 `O(n)`。

## 边界条件与本地验证

初始前缀异或 `0` 出现一次，确保从下标 0 开始的子数组被计入；全零元素和重复前缀都会正确累计组合数。
