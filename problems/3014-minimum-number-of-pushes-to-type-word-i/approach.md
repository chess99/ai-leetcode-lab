# 解题记录

## 思路

每八个不同字符增加一次按键次数。

可重映射的按键有 `2` 到 `9` 共八个。题目保证单词中的字符互不相同，因此只需把最多八个字符放在各按键的第一层、接下来八个放在第二层，依此类推。第 `index` 个字符的最少按键次数为 `index // 8 + 1`，累加即可。

## 复杂度

设单词长度为 `n`。时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## 边界条件与本地验证

长度不超过 `8` 时每个字符只需按一次；第 `9` 个字符开始需要按两次。使用长度分别为 `1`、`8`、`9`、`16` 和 `26` 的互异字符单词验证分层计数。
