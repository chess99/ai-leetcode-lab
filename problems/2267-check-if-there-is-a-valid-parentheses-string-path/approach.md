## 思路

网格 DP 记录到达每个格子时可能的未闭合左括号数量。从上方和左方状态合并，再按当前字符加一或减一；余额不能为负，也无需保留大于剩余路径长度的状态，因为之后无法归零。路径长度必须为偶数，起点必须是左括号且终点必须是右括号，可先快速排除。

## 复杂度

路径余额最多为 `m+n`，时间 `O(mn(m+n))`；滚动行集合空间 `O(n(m+n))`。

## 边界条件与本地验证

覆盖单行/单列、前缀提前为负及终点仍有余额。题面样例得到真、假；随机至多 6×6 网格枚举所有向右/向下路径核对 1500 组。
