## 思路

只检查区间 `(n / 2, n]` 内整数的二进制表示。因为其中任意数的二进制表示均已出现时，去掉最高位得到的后缀正好是一个不超过 `n / 2` 的正整数的二进制表示，也必然作为子串出现。故从 `n` 递减到 `n // 2 + 1`，逐个检查其二进制字符串是否是 `s` 的子串即可。

## 复杂度

设字符串长度为 `m`。需要检查 `O(n)` 个数，每次子串查找最多 `O(m)`，时间复杂度为 `O(nm)`；除二进制字符串临时对象外额外空间为 `O(log n)`。

## 边界条件与本地验证

- `n = 1` 时只检查二进制串 `"1"`。
- 从 `n // 2 + 1` 开始，避免遗漏上半区间；检查顺序不影响结果。
- 本地验证了题目示例、`n = 1` 和缺失较大二进制子串的反例。
