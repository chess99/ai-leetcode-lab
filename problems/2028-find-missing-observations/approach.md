# 解题思路

## 思路

## 算法

由平均值可得全部观测值的目标总和，减去已知骰子点数之和即可得到缺失点数总和 `missing_sum`。每个缺失值必须在 `[1, 6]`，所以只有 `n <= missing_sum <= 6n` 时有解。将 `missing_sum` 除以 `n`，先给所有位置商 `base`，再将余数逐个加一。

## 正确性证明

目标平均值唯一确定缺失数据的总和 `missing_sum`。若该和不在 `n` 到 `6n` 之间，任意 `n` 个骰子点数均无法达到它，故无解。反之，构造中的每个值为 `base` 或 `base + 1`，且因为总和可行，它们都在 `[1, 6]` 内；其总和为 `n * base + remainder = missing_sum`。与已知数据合并后总和满足目标平均值，因此构造正确。

## 复杂度分析

求已知和与构造答案各需线性时间，时间复杂度为 `O(m + n)`，除返回数组外额外空间复杂度为 `O(1)`。

## 边界情况

- 缺失总和小于 `n` 或大于 `6n` 时返回空数组。
- 余数为 0 时所有缺失值相同。
- 缺失数量可很大，直接构造而不做搜索。
