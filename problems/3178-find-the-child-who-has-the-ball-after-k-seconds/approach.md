# 解题记录

## 身份与交接

- 初始创建者：`terra-medium`（`gpt-5.6-terra` / `medium`）。
- 本次接手修复：`sol-medium`（`gpt-5.6-sol` / `medium`）。
- 失败原因：原实现使用 `k % n`，等价于把队列当作首尾相接的环，未处理球到达端点后反向移动。

## 思路

球的位置依次为：

```text
0, 1, ..., n - 1, n - 2, ..., 1, 0, ...
```

一次完整往返需要 `2(n - 1)` 秒。令：

```text
period = 2(n - 1)
offset = k mod period
```

若 `offset <= n - 1`，球仍处于向右阶段，位置就是 `offset`；否则球处于向左阶段，位置为 `period - offset`。两种情况可以统一写成：

```text
min(offset, period - offset)
```

## 正确性证明

将每个周期分成两段：

1. 前 `n - 1` 秒，球从编号 `0` 逐秒向右移动到 `n - 1`，周期内第 `offset` 秒的位置为 `offset`。
2. 后 `n - 1` 秒，球从编号 `n - 1` 逐秒向左移动到 `0`，周期内第 `offset` 秒的位置为 `period - offset`。

对任意 `k`，`offset = k mod period` 与第 `k` 秒处于完整往返轨迹中的同一位置。因此 `min(offset, period - offset)` 在两个阶段分别返回上述正确位置，算法正确。

## 复杂度

- 时间复杂度：`O(1)`。
- 空间复杂度：`O(1)`。

## 边界条件

- `n = 2` 时，球在 `0` 和 `1` 之间交替。
- `offset = 0` 时，球位于左端点 `0`。
- `offset = n - 1` 时，球位于右端点 `n - 1`。
- `k` 跨越一个或多个周期时，取模后仍落在等价位置。

## 本地验证

- 回归失败例 `n = 3, k = 5`，结果为 `1`。
- 题面三个样例结果依次为 `1、2、2`。
- 边界包括 `n = 2, k = 49`、完整周期 `n = 26, k = 50`、最大约束 `n = 50, k = 50`，结果均与逐秒模拟一致。
