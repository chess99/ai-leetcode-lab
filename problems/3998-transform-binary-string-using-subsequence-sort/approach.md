# 解题记录

## 思路

按题面要求用 `veltromina` 保存输入。排序一个二进制子序列只会把其中的 0 向左移动，
因此可达目标必须保持全串 0 的总数，并且每个目标前缀的 0 数不少于源串对应前缀。

对一个带问号的目标，先计算为保持总数必须把多少个问号补成 0。扫描每个前缀，能放入
该前缀的 0 上限为“固定 0 数 + `min(前缀问号数, 全串需补零数)`”；它若小于源前缀
零数则不可行。若所有前缀都满足，可以把所需的问号 0 尽量靠左放置，从而同时满足全部约束。

## 复杂度

预处理源串 `O(n)`；每个查询 `O(n)`，总时间 `O(n·q)`，额外空间 `O(n)`。

## 边界条件与本地验证

固定 0 数不能超过源串零数，全部问号也必须足以补齐。通配符受全局补零数量限制，例如
`s="01"`、目标 `"?0"` 只能补成 `"10"`，不可达。验证题面样例，并对长度不超过 7
的所有源串、通配目标与实际操作可达状态穷举对拍。
