## 思路
按原顺序迭代插入节点，显式构造同一棵二叉搜索树。再用显式遍历自底向上计算每棵子树的节点数和重排方案数：左右子树内部顺序分别保持可行，并用组合数选择它们在根之后的交错位置。最后扣除原排列。

## 复杂度
迭代插树最坏时间 $O(n^2)$，自底向上统计时间 $O(n)$，空间 $O(n)$。

## 边界条件与本地验证
长度小于 3 的子树只有一种顺序；结果取模；题目元素互异。显式遍历避免严格递增或递减的 1000 节点树触发 Python 递归上限。
