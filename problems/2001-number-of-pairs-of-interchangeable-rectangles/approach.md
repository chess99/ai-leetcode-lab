# 解题思路

## 思路

## 算法

用最大公约数将每个矩形的宽高比约分为二元组 `(width / gcd, height / gcd)`。相同比值的矩形恰好可以互换。遍历时，当前矩形能和此前同一二元组的所有矩形各组成一对，因此先把该组已有数量加入答案，再将该组计数加一。

## 正确性证明

约分后的二元组唯一表示一个正整数宽高比，因此两个矩形可互换当且仅当它们的二元组相同。处理当前矩形时，`counts[ratio]` 正是此前所有与它可互换的矩形数量；加入该值恰好计入所有以当前矩形为后一个端点的有效对，且每对只会在后一个端点处理时计入一次。故最终答案为全部可互换矩形对的数量。

## 复杂度分析

设矩形数为 `n`，每次求最大公约数耗时 `O(log M)`，其中 `M` 为边长上界。总时间复杂度为 `O(n log M)`，哈希表空间复杂度为 `O(n)`。

## 边界情况

- 所有比值都不同，答案为 `0`。
- 所有矩形比值相同，遍历累计得到 `n * (n - 1) / 2`。
- 使用整数约分，避免浮点数比较误差。
