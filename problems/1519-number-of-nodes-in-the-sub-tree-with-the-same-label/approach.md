## 思路

用显式栈进行带进入、退出事件的深度优先遍历，避免链式树导致 Python 递归栈溢出。维护已经退出的节点中 26 个标签的全局计数；进入节点时记录其自身标签的当前计数，退出节点时先把自身加入计数，再用当前计数减去进入前计数，差值恰为该节点子树中相同标签的数量。

## 正确性

一个节点从进入到退出之间，DFS 恰好完整处理它的所有后代，且不会处理其子树外的新节点。因此该标签的全局计数增量恰好来自该节点子树；退出时再计入节点自身后，计数差就是子树内与节点标签相同的节点数。对每个节点执行同样计算，得到全部正确答案。

## 复杂度

每个节点和每条边只处理常数次，时间 `O(n)`，邻接表、显式栈和辅助数组空间为 `O(n)`。

## 边界条件与本地验证

- 单节点子树计数为 1。
- 显式栈可处理题目上限下的链式树。
- 本地验证了题目示例。
