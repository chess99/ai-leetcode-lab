## 思路

Python 字符串的 `find` 返回子串首次出现的下标；若不存在则返回 `-1`，与题目返回约定一致。

## 复杂度

- 时间复杂度：由字符串查找实现决定，最坏可记为 `O(nm)`。
- 空间复杂度：`O(1)`，不额外构造与输入规模相关的数据结构。

## 边界条件与本地验证

- 匹配发生在开头、结尾或不存在时分别返回对应下标或 `-1`。
- 已用题面两个示例、`"aaa"` 查找 `"aa"` 和单字符不匹配案例做本地断言验证。
