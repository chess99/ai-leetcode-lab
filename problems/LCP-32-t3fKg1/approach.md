# 解题记录

- AI 客户端：Codex Desktop；模型：gpt-5.6-terra；推理档位：medium；Profile：terra-medium；轮次：1

## 思路

按任务结束时间升序处理。对 `[start,end]`，先统计其中已经选择的开机时刻；不足的部分尽量从 end 向左补，能给未来任务留下更大复用空间。由于坐标可达 1e9，将所有 start 和 end+1 压缩成连续整段，线段树维护每段容量、已选数量和整段全选懒标记，支持区间查询及从右到左批量填充。

## 复杂度

时间 `O(Q log Q)`，空间 `O(Q)`。

## 边界条件与本地验证

覆盖单点任务、整段一次性填满和懒标记下推。两个官方样例通过；随机小坐标实例与枚举所有开机子集的 oracle 对拍 10000 组通过，并据此修复过一次懒传播缺失。
