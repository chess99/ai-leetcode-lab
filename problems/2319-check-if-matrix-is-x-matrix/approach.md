## 思路

遍历矩阵的每个位置。满足 `i == j` 或 `i + j == n - 1` 的位置位于两条对角线上，值必须非零；其他位置的值必须为零。任一位置不符合即可判定为假。

## 复杂度

矩阵边长为 n，时间复杂度为 O(n²)，额外空间复杂度为 O(1)。

## 边界条件与本地验证

覆盖最小方阵、两条对角线交点、对角线上出现零，以及非对角线位置出现非零值的情况。奇数阶矩阵的中心点同时属于两条对角线，只需检查一次非零条件。
