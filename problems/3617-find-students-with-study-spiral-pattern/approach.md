## Terra 失败交接

首次候选由 `gpt-5.6-terra`（`terra-medium`）生成，远程结果为 MySQL Runtime Error（0/16），错误定位在第 20 行 CTE 名 `groups` 附近。`GROUPS` 是 MySQL 窗口帧语法中的关键字，把它直接用作未转义的 CTE 名会触发解析错误。

本候选不只改名。首次方案先按日期断档切段，再在每段中寻找周期，这会产生两个语义风险：一名学生只要某个局部片段合格就可能入选，即使该学生的完整学习序列存在超过 2 天的断档；同一学生有多个合格片段时还可能输出多行。题目要求判断遵循该模式的学生，因此本方案改为按学生的完整有序序列做一次整体判断。

## 算法 / SQL 方案

1. 在每名学生内部按 `(session_date, session_id)` 排序。`session_id` 是唯一键，可在同一天有多条记录时提供确定顺序。计算行号 `rn` 和上一条记录日期。
2. 按学生汇总：
   - `session_count`：学习记录数；
   - `cycle_length`：不同学科数；
   - `total_study_hours`：全部模式记录的学习时长之和；
   - `has_date_gap`：是否存在相邻记录日期相差超过 2 天。
3. 先筛掉学科少于 3 门、记录数少于两个周期或存在日期断档的学生。对剩余记录用 `MOD(rn - 1, cycle_length)` 计算周期槽位。
4. 对每个学生的每个槽位统计不同学科数。只有槽位数恰好等于 `cycle_length`，并且每个槽位都始终只出现一门学科时，完整序列才按固定顺序循环。
5. 连接学生信息，并按循环长度、总学习时长依次降序排序。

记录数不要求是循环长度的整数倍。例如 `A,B,C,A,B,C,A` 已包含两个完整周期，最后一条只是第三个周期的前缀，且仍遵循同一循环顺序；它应被计入模式总时长。

## 正确性证明

设某名通过筛选的学生有 `K = cycle_length` 门不同学科。

首先，汇总条件保证 `K >= 3`、记录数至少为 `2K`，所以序列至少容纳两个完整周期；`has_date_gap = 0` 保证按时间排序后任意相邻两条记录的日期间隔都不超过 2 天。

其次，第 `i` 条记录被放入槽位 `(i - 1) mod K`。槽位校验要求每个槽位的不同学科数都是 1，因此任意相差 `K` 个位置的记录属于同一学科。又因为完整序列一共恰有 `K` 门不同学科，且前 `K` 个位置覆盖全部 `K` 个槽位，所以这些槽位分别对应 `K` 门不同学科。于是从第 `K + 1` 条记录开始，每条记录都等于前一周期同槽位的学科，整个序列按长度 `K` 的固定学科顺序重复。

因此，输出的每名学生都满足至少 3 门不同学科、至少两个完整周期、固定重复顺序和相邻日期间隔不超过 2 天。反过来，任何满足题意的学生，其相同周期槽位必然始终是同一学科，且所有汇总条件均成立，所以一定会通过查询，不会被遗漏。

## 复杂度

设学习记录总数为 `N`。窗口函数需要按学生排序，时间复杂度为 `O(N log N)`；后续分组和连接为 `O(N)` 量级。CTE 中间结果占用 `O(N)` 空间。

## 边界条件与验证重点

- 同一天多条记录：用唯一的 `session_id` 打破日期并列，顺序稳定。
- 恰好两个周期：允许并正确识别。
- 两个完整周期加第三周期前缀：允许，前缀也属于循环序列并计入总时长。
- 少于 3 门学科或少于 `2K` 条记录：排除。
- 任一相邻日期恰好相隔 2 天：允许；超过 2 天：整名学生排除。
- 某个周期槽位出现不同学科：排除。
- 学生没有学习记录：不会进入汇总结果。
- 一名学生至多输出一行。

## 本地验证结果

在不调用仓库 CLI、远程判题或网络的前提下，将 MySQL 专有的 `DATEDIFF` 替换为 SQLite 等价日期差表达式，并为 `MOD` 注册等价函数，执行了兼容子集验证：

- 示例型的 3 科、4 科完整循环均正确入选，循环长度、总时长与排序正确。
- 2 科、记录不足、顺序破坏、超过 2 天断档以及只有局部片段形成循环的用例均正确排除。
- 恰好两个周期、同日多条记录、两个完整周期后追加下一周期前缀的用例均正确入选。
- 对 11,840 个序列进行了性质测试（长度 1～8 的三学科序列穷举，并补充固定随机种子的四学科序列与断档用例）；查询结果与“至少两周期、槽位相等、整体无断档”的独立判定逐项完全一致。

MySQL 静态审查确认本查询使用 MySQL 8 支持的 CTE、`ROW_NUMBER`、`LAG`、`DATEDIFF` 和 `MOD`，且不再包含冲突的 `groups` 标识符。SQLite 验证仅替换上述两个方言函数，没有改变窗口、分组、连接及筛选逻辑。
