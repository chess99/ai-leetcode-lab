## 失败根因

旧实现用字典字面量一次写出四种运算：
`{'+': a+b, '-': a-b, '*': a*b, '/': int(a/b)}[token]`。Python 构造字典时会先计算全部四个值，所以即使当前运算符是 `+`，也仍会执行 `a / b`。当右操作数恰为 `0` 时，合法的加减乘表达式因此错误触发 `ZeroDivisionError`。

此外，`int(a / b)` 会先把任意精度整数转换成浮点数。中间乘积很大时可能溢出或丢失精度，因此本次一并改为纯整数除法。

## 算法

顺序扫描后缀表达式并维护一个整数栈：

1. 遇到整数就压栈。
2. 遇到运算符时，先弹出的数是右操作数，再弹出的数是左操作数。
3. 仅执行当前运算符对应的分支，再把结果压回栈。
4. 除法先计算 `abs(left) // abs(right)`，再根据两数符号是否不同决定结果符号，从而完全用整数运算实现向零截断。

## 正确性证明

扫描任意前缀后，栈从底到顶恰好保存这个前缀中所有“已经完整出现、但尚未被后续运算符合并”的子表达式值。

- 数字是一个完整子表达式，将其值压栈后不变量成立。
- 对于运算符，合法后缀表达式保证栈顶两个值分别来自它的左、右子表达式；按先右后左的顺序弹出，仅执行该运算，再压回所得值，等价于把这两个子表达式合并成一个完整子表达式，因此不变量继续成立。

完整表达式扫描结束时只剩一个未合并子表达式，它就是整个表达式，所以栈中唯一的值是正确答案。除法的绝对值商等于整数商的绝对值，按操作数符号恢复符号后，结果恰为向零截断的商。

## 复杂度

设 token 数为 `n`。每个 token 只入栈或参与一次运算，时间复杂度为 `O(n)`；最坏情况下栈保存 `O(n)` 个操作数，空间复杂度为 `O(n)`。

覆盖单个整数、四种运算、右操作数为零的加减乘、负数除法、结果为零、深层嵌套表达式和大整数中间结果。另使用独立递归表达式生成器及独立求值器进行随机对拍，并验证长度上限附近的合法表达式性能。
