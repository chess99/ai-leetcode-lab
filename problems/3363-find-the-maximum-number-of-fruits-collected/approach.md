## 旧实现问题

terra-medium 的实现已经抓住了“主对角线固定 + 两侧分别动态规划”的主体思路，但复用左下角孩子的 DP 时使用了水平镜像 `fruits[i][n - 1 - j]`。左下角孩子每一步增加的是列坐标，若要把列当作 DP 的时间轴，正确变换应当是转置，即读取 `fruits[j][i]`。错误的镜像会访问不属于该路径的房间，回归用例因此得到 77，而不是 100。

## 算法

从 `(0, 0)` 出发的孩子必须在恰好 `n - 1` 步内让行、列坐标都从 0 变成 `n - 1`。每一步两者至多各增加 1，所以它只能每步走到 `(i + 1, j + 1)`，其收益固定为主对角线之和。

对右上角孩子按行做动态规划。令 `dp[j]` 表示当前行到达第 `j` 列时能收集的最大水果数，转移来自上一行的 `j - 1`、`j`、`j + 1`。在第 `i` 行：

- 从起点出发，列坐标不可能小于 `n - 1 - i`；
- 为在剩余 `n - 1 - i` 步内到达终点，列坐标不能小于 `i`。

因此只需枚举 `j >= max(i, n - 1 - i)`。主对角线房间已由第一个孩子清空，其贡献记为 0。

把矩阵转置后，左下角孩子的起点变成右上角，原来的“每步列坐标加一、行坐标至多变化一”也变成同一个逐行转移。因此用读取 `fruits[j][i]` 的方式再运行一次相同 DP。

## 正确性证明

第一个孩子的路径如上所述被步数约束唯一确定，故主对角线之和必然且可以全部取得。

对右上角孩子，第 `i` 次移动后必在第 `i` 行。DP 初态是其起点；每个状态恰好考察题目允许的三个前驱，故归纳可知 `dp[j]` 等于所有到达 `(i, j)` 的合法路径中的最大收益。能最终到达右下角的状态必满足 `j >= i`，而从起点可达又要求 `j >= n - 1 - i`，所以裁剪不会删除任何完整合法路径。最终状态因而给出该孩子的最优收益。转置保持房间权重及相邻移动关系，所以第二次 DP 同理给出左下角孩子的最优收益。

除终点外，右上角孩子的可行完整路径位于主对角线上方，左下角孩子位于主对角线下方；主对角线水果已单独计入。三部分没有重复收益，且两侧选择互不影响，因此三者最优收益之和就是全局最优答案。

## 复杂度

两次 DP 都至多处理 `n^2` 个状态，每个状态检查三个前驱，时间复杂度为 `O(n^2)`；使用滚动数组，额外空间复杂度为 `O(n)`。

## 边界与本地验证

- `n = 2` 时三名孩子分别取得三个起点和公共终点，所有房间恰好计入一次。
- 全零矩阵、对角线非零矩阵及侧边最优路径需要连续折返的情况均由相同状态转移覆盖。
- 使用独立路径枚举 oracle，对 `n = 2..5` 的小规模随机矩阵枚举三名孩子的全部合法路径并按房间并集计分：本地等价 DP 的 600 例全部一致，主控 Python 环境直接执行 `solution.py` 的 320 例也全部一致。
- 回归用例 `[[1,2,3,4],[5,6,8,7],[9,10,11,12],[13,14,15,16]]` 得到 100；题面第二个样例得到 4；全零及对角线边界用例也符合预期。
- 最大约束 `n = 1000` 的确定性矩阵在主控 Python 环境直接执行约 0.185 秒；本地等价实现约 0.026 秒。未使用仓库 CLI 或远程判题。
