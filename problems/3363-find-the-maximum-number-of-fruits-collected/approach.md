# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

第一位孩子只能沿主对角线移动，收益固定。另两位孩子分别活动在主对角线两侧的三角区域，互不相交；对每一侧做逐行动态规划，转移来自上一行允许的三个列位置。DP 完整走到右下终点，终点果实已在对角线中计入，因此侧面终点贡献记为 0。

## 复杂度

时间 `O(n^2)`，滚动数组空间 `O(n)`。

## 边界条件与本地验证

处理 `n=2`、边界列转移和对角线不重复计数。修复了原实现少走最后一步的问题；题面样例和小网格枚举两名孩子所有路径均通过。
