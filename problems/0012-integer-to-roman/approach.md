# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

按数值从大到小列出所有罗马数字片段，并把减法组合（如 `CM`、`IV`）也作为独立片段。对每个数值做 `divmod`，将商个对应片段加入答案，余数继续由更小片段表示。这个表覆盖题目范围内的标准写法。

## 复杂度

- 时间复杂度：O(1)，映射表长度固定为 13。
- 空间复杂度：O(1)，除输出字符串外只使用固定大小额外空间。

## 边界条件与本地验证

- 减法记法由表项直接处理：4、9、40、90、400、900。
- 最小值 1 和最大值 3999 都可由同一套表表示。
- 验证：`3 -> "III"`、`58 -> "LVIII"`、`1994 -> "MCMXCIV"`、`3999 -> "MMMCMXCIX"`。
