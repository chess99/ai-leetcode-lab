# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

以点分割两个版本号，按下标比较每段转换后的整数；较短版本缺少的段按零处理。遇到首个不同段立即返回比较结果，全部相同则返回 0。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(n)，用于分割后的段列表。

## 边界条件与本地验证

- 前导零由整数转换忽略；尾随零和缺失段等价。
- 验证：`"1.2","1.10" -> -1`、`"1.01","1.001" -> 0`、`"1.0","1.0.0.0" -> 0`。
