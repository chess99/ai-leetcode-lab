## 思路

用数组记录每个单元的 `mID`，0 表示空闲。分配时从左到右扫描连续空闲段，首次达到 `size` 即填入并返回起点；释放时扫描数组并清空所有相同 `mID`。

## 复杂度

每次 `allocate` 与 `freeMemory` 均为 `O(n)` 时间，数组占 `O(n)` 空间。

## 边界条件与本地验证

连续空闲段不足时返回 `-1`；同一 ID 的多个分段都会释放；未分配的 ID 返回 0。已用题面操作序列验证。
