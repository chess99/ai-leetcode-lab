# 解题思路

## 思路

## 算法

预处理 `suffix_min[i]`，表示从 `i` 到末尾的最小值；从左到右维护当前位置左侧的最大值 `prefix_max`。对位置 `i`，若 `prefix_max < nums[i] < suffix_min[i + 1]`，它严格大于所有左侧数且严格小于所有右侧数，贡献 2。否则再检查相邻三元组是否递增，满足则贡献 1。

## 正确性证明

`prefix_max` 精确等于位置 `i` 左侧所有元素的最大值，`suffix_min[i + 1]` 精确等于右侧所有元素的最小值。因此两者夹住 `nums[i]` 当且仅当题目的全局严格不等式成立，算法正确赋值 2。全局条件不成立时，算法再按题意直接检查相邻元素，恰在局部严格递增时赋值 1，否则为 0。每个合法位置均被处理一次，故总和正确。

## 复杂度分析

两次线性扫描，时间复杂度为 `O(n)`；后缀最小值数组占用 `O(n)` 空间。

## 边界情况

- 数组长度为 3 时只检查中间元素。
- 有相等元素时严格不等式不成立，不会被误计。
- 全局条件优先于局部条件，符合题目定义。
