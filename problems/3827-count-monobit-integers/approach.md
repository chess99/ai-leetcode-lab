## 思路

除 0 外，单比特数的二进制必须全为 1，即依次为 1、3、7、15……。从 0 开始计数并生成这些数直到超过 n。

## 复杂度

时间复杂度 O(log n)，额外空间复杂度 O(1)。

## 边界条件与本地验证

0 的二进制表示为 `0`，也应计入。已进行 Python 语法检查及最小断言。
## 思路

枚举范围内整数并检查二进制表示是否为连续的一后接零。

## 复杂度

时间与范围长度成正比，空间 `O(1)`。

## 边界条件与本地验证

覆盖零和一。
