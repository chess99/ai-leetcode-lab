## 思路

若切成若干等和连通块，每块目标和必须是总和的约数。按目标和从小到大尝试，相当于优先尝试更多组件。先将树根化并得到父节点与遍历序；逆序累计子树和，等于目标时就在父边切断，小于目标则合并给父节点，大于目标立即失败。第一个可行目标产生最多删除边数。

## 复杂度

设总和约数数为 `d`，时间 `O(n*d+sqrt(sum))`，最坏 `O(nsqrt(sum))`；图和工作数组空间 `O(n)`。

## 边界条件与本地验证

单节点不能删除边；目标和不能小于最大节点值。题面样例得到 `2、0`；随机 `n<=10` 的树枚举全部切边子集并比较各组件和，对拍完成。两万节点烟测约 0.04 秒。
