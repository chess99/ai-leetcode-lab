# 解题思路

## 算法

一次操作只会使数值加减 `x`，因此所有元素对 `x` 的余数必须相同，否则不可能变为同一数。可行时将网格展平并排序，选择中位数作为目标值。每个元素变到目标值的操作数为 `abs(value - target) / x`，累加即可。

## 正确性证明

加减 `x` 不改变模 `x` 的余数，所以余数不一致是无解的必要条件；余数一致时任意元素均可通过若干次操作变到任一现有元素值，故可行。把所有值同时减去公共余数并除以 `x` 后，问题变为选择一个整数目标以最小化绝对距离之和。绝对距离和由中位数最小化，因此选择排序后的中位数并累加对应步数得到最小操作数。

## 复杂度分析

设元素总数为 `N`。展平和检查耗时 `O(N)`，排序耗时 `O(N log N)`，总时间复杂度为 `O(N log N)`，空间复杂度为 `O(N)`。

## 边界情况

- 只要存在不同模 `x` 的余数，立即返回 `-1`。
- 元素数为偶数时任选两个中位数之一都最优。
- 已经为单值网格时，答案为 0。
