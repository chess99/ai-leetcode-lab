# 解题思路

## 算法

若数组长度为奇数，直接无解。统计每个值的频次后按值从小到大处理。对正数 `x`，尚未处理的每个 `x` 必须在双倍数组中匹配一个 `2x`，因此检查 `count[2x]` 是否足够，足够则扣除并将这些 `x` 加入原数组。零需要与另一个零配对，故其频次必须为偶数。

## 正确性证明

按升序处理时，正数 `x` 不可能是任何尚未处理数的两倍；它只能作为原数组元素，必须匹配同数量的 `2x`。算法正好执行这一必要匹配，匹配不足时不存在合法原数组。匹配成功时，扣除的 `2x` 与加入的 `x` 一一对应。零只能和零配对，偶数检查同样充要。故算法返回非空结果时可重建 `changed`，返回空结果时无解。

## 复杂度分析

计数耗时 `O(n)`，排序不同数值耗时 `O(n log n)`，总时间复杂度为 `O(n log n)`，空间复杂度为 `O(n)`。

## 边界情况

- `changed` 长度为奇数时无解。
- 零的数量为奇数时无解，偶数时一半属于原数组。
- 某个数的双倍数量不足时立即返回空数组。
