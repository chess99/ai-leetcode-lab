# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

输入区间已按起点排序且彼此不重叠。先加入所有完全位于新区间左侧的区间；再合并所有与新区间相交或相接的区间，持续更新新起点和终点；随后加入合并后的新区间，并接上所有右侧区间。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(n)，用于结果数组。

## 边界条件与本地验证

- 空输入会直接返回新插入区间。
- 新区间在全部区间之前或之后时不触发合并。
- 端点相接也应合并，故使用严格小于判断左侧、使用小于等于判断重叠。
- 验证：`[[1,3],[6,9]], [2,5] -> [[1,5],[6,9]]`、`[[1,2],[3,5],[6,7],[8,10],[12,16]], [4,8] -> [[1,2],[3,10],[12,16]]`、`[], [5,7] -> [[5,7]]`。
