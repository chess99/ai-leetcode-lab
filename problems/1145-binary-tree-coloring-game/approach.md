## 思路

节点 `x` 将树分成左子树、右子树和其余父侧三块。二号玩家若选择其中最大的一块，就能占据该连通区域；当该块节点数超过 `n // 2` 时必胜。一次 DFS 同时统计子树大小并记录 `x` 的左右大小。

## 复杂度

设节点数为 `N`。DFS 时间 `O(N)`，递归栈最坏为 `O(N)`。

## 边界条件与本地验证

- `x` 为根时父侧大小为 0。
- 只有任一分块严格超过一半才获胜。
- 对 3000 棵随机奇数节点树随机选择首位玩家节点，独立计算左右子树和父侧三个连通块大小，与胜负判定对拍。
