# 2501. 数组中最长的方波

## 思路

方波在排序后严格递增（题目数值至少为 `2`），所以可按数值从小到大做动态规划。去重后遍历每个值 `x`：若 `x` 是完全平方数，且其整数平方根 `r` 已在数组中，则以 `x` 结尾的最长方波长度为 `dp[r] + 1`；否则只能从 `x` 自身开始，长度为 `1`。

最后最大长度至少为 `2` 才是题目定义的方波，否则返回 `-1`。

## 正确性说明

任意以 `x` 结尾且长度至少为二的方波，其前一个数必须唯一地等于整数平方根 `r`，并且 `x = r^2`。由于按升序处理，`r < x` 已经处理完毕；若 `r` 存在，接在以 `r` 结尾的最长方波后可得到长度 `dp[r] + 1` 的合法方波，且不存在其他前驱可得到更长序列。

若 `x` 不是数组中某个整数 `r` 的平方，它不能接在任何方波之后，最长长度只能为 `1`。由归纳可知每个 `dp[x]` 正确，取其最大值并按长度下限转换，即得到题目答案。

## 复杂度

设去重后元素个数为 `u`。排序时间复杂度为 `O(u log u)`，动态规划时间复杂度为 `O(u)`，空间复杂度为 `O(u)`。

## 边界情况

- 数组中存在重复数字时，去重不会影响严格递增的平方链。
- 没有任意平方关系时，最大长度为 `1`，返回 `-1`。
- 链可从任意非平方数开始，例如 `2 -> 4 -> 16`。
