## sol-medium 交接与修复

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-sol
- 推理档位：medium
- Profile：sol-medium
- 修复方向：对角线滚动动态规划

第一次操作只有三种选择，所以所有操作的固定目标分数只能是：首两项之和、末两项之和、首末项之和。去重后逐一计算这些目标分数对应的最大操作数。

固定目标分数 `target`。令 `dp[l][r]` 表示当前剩余连续区间为 `nums[l..r]` 时，之后最多还能完成多少次分数为 `target` 的操作。若对应端点和等于 `target`，有三种转移：

- 删除左边两个：`1 + dp[l + 2][r]`；
- 删除右边两个：`1 + dp[l][r - 2]`；
- 删除左右端点：`1 + dp[l + 1][r - 1]`。

所有转移都从长度为 `length` 的区间转到长度为 `length - 2` 的区间。因此按区间长度递增计算时，当前长度的整条对角线只依赖长度少 2 的上一条对角线。实现中用 `previous` 和 `current` 两个一维数组滚动，不再保存整个二维状态表。偶数 `n` 从长度 0 的空区间开始，奇数 `n` 从长度 1 的单元素区间开始，只计算与 `n` 同奇偶性的区间。

## 正确性证明

固定一个候选目标分数 `target`。

对区间长度归纳。长度小于 2 时不能操作，动态规划值为 0，结论成立。假设所有长度为 `length - 2` 的区间都已得到正确最优值。对于长度为 `length` 的区间 `[l, r]`，任何合法的下一次操作必定且只能是删除左边两个、右边两个或左右端点之一；只有相应两数之和等于 `target` 时该选择才合法。完成该操作后，剩余区间恰是三条转移所指向的某个长度为 `length - 2` 的区间。根据归纳假设，转移后的动态规划值给出了该选择之后的最优操作数；对全部合法首步取最大值，就既不会漏掉任何合法方案，也不会计入非法方案。因此 `dp[l][r]` 正确。

整个操作序列的目标分数由第一次操作决定，而第一次操作只能产生枚举的三个候选分数。对这些分数的 `dp[0][n-1]` 取最大值，故得到全局最多操作数。

## 复杂度

候选目标分数最多 3 个。每个目标分数计算 `O(n^2)` 个区间，每个区间做常数次转移，因此总时间复杂度为 `O(n^2)`。滚动数组同时最多保存两条长度对角线，额外空间复杂度为 `O(n)`。

## 边界条件

- `n = 2` 时三个首次选择实际对应同一对元素，目标分数去重后答案为 1。
- 奇数长度最终会留下一个元素；单元素区间作为值为 0 的基础状态。
- 若某个区间三种端点组合均不满足目标分数，该状态为 0。
- 三个初始分数可能相同，使用集合去重不影响答案，并避免重复计算。
