## 思路

只需确定 `arr1`，因为 `arr2[i] = nums[i] - arr1[i]`。设当前 `arr1[i]=x`、前一项为 `y`，两个单调条件给出 `y <= x` 且 `nums[i-1]-y >= nums[i]-x`，即 `y <= x + nums[i-1]-nums[i]`。

因此合法上一值是从 0 到两个上限的较小值。对上一层 DP 做前缀和，即可常数时间得到每个新状态。

## 复杂度

令 `M=max(nums)`，时间复杂度为 `O(nM)`，空间复杂度为 `O(M)`。

## 边界条件与本地验证

所有状态都限制在非负且不超过当前 `nums[i]`；上限为负时该状态不可达。每步和最终答案均取模。本地枚举随机小数组的全部 `arr1`，同时检查 `arr2` 单调性，对拍一致。
