# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

创建 `n × n` 矩阵，用上、下、左、右四个边界描述尚未填充的区域。每轮顺时针填充上边、右边、下边、左边，填完一条边就收缩它；填充后两条边前检查边界是否仍有效，避免中心行或列被重复写入。

## 复杂度

- 时间复杂度：O(n²)。
- 空间复杂度：O(n²)，用于返回矩阵。

## 边界条件与本地验证

- `n = 1` 时只填入 `1`。
- 奇数边长的中心格通过边界检查恰好写入一次。
- 验证：`3 -> [[1,2,3],[8,9,4],[7,6,5]]`、`1 -> [[1]]`、`2 -> [[1,2],[4,3]]`。
