## 思路

把每个值为 0 的格子视作图节点，八个相邻方向均可走且边权相同，因此从左上角进行广度优先搜索。队列中保存坐标和路径长度；格子入队时立即标记为已访问，避免重复入队。BFS 首次到达右下角时得到的路径长度最短。

## 复杂度

时间复杂度为 `O(n^2)`，每个格子至多访问一次；队列空间复杂度为 `O(n^2)`。

## 边界条件与本地验证

起点或终点被阻塞时直接返回 `-1`；`1 x 1` 且唯一格子为 0 时返回 1；无路可达时最终返回 `-1`。已用题目三个样例验证。
