# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

先记录商的符号，再将两个操作数转为非负数。每轮把除数不断左移，得到不超过当前被除数的最大倍增值；从被除数中减去它，并把相同倍数累加到商。重复至余数小于除数，最后恢复符号并截断至 32 位有符号整数范围。

## 复杂度

- 时间复杂度：O(log² |dividend|)，外层最多按二进制位数迭代，内层寻找每轮最大倍增值。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 异号结果向零截断，通过先取绝对值的整数减法实现。
- `-2^31 / -1` 是唯一超过上界的组合，最终截断为 `2^31 - 1`。
- 题目保证除数不为零。
- 验证：`10 / 3 -> 3`、`7 / -3 -> -2`、`-2147483648 / -1 -> 2147483647`、`-2147483648 / 2 -> -1073741824`。
