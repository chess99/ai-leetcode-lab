## 思路

把 0 看成 `-1`，把 1 看成 `+1`，问题就转化为寻找和为 0 的最长连续子数组。扫描时维护累计差值 `balance`；同一个差值若在两个位置出现，说明中间一段的 0 和 1 数量相等。哈希表只保存每个差值第一次出现的下标，从而在再次遇到它时得到尽可能长的区间。预先记录差值 0 出现在下标 `-1`，兼容从开头开始的区间。

## 复杂度

一次线性扫描即可完成，时间复杂度为 `O(n)`；差值取值数量至多为 `2n + 1`，实际记录不超过 `n + 1` 项，空间复杂度为 `O(n)`。

## 边界条件与本地验证

全 0 或全 1 时没有非空平衡区间，结果为 0；长度为 2 的 `[0,1]` 和整个数组平衡的情况由初始下标 `-1` 正确处理。验证包含空数组、单元素、交替序列和嵌套平衡区间，并对随机 0/1 小数组与枚举所有子数组计数的朴素解进行了对拍。
