## 思路

在单独元素左侧，每个成对元素的第一项位于偶数下标；在其右侧，这一规律反转。二分时将中点对齐到偶数下标：若它和下一项相同，单独元素在右侧；否则在左侧（含当前中点）。区间收缩到一个下标即为答案。

## 复杂度

二分查找时间复杂度 `O(log n)`，只使用常数个变量，空间复杂度 `O(1)`。

## 边界条件与本地验证

- 单独元素可在首位、末位或中间。
- 数组长度为 1 时循环不进入，直接返回唯一元素。
- 验证了 `[1,1,2,3,3,4,4,8,8] -> 2`、`[3,3,7,7,10,11,11] -> 10`、`[0] -> 0` 与 `[1,1,2] -> 2`。
