# 解题记录

## 思路

直接模拟每轮固定递减的移除数量；无法操作的一方失败。

Alice 首次需要移除 `10` 颗，此后需求依次为 `9、8、...`。只要当前石头足够，就扣除本轮数量并交换玩家；第一次石头不足时，当前玩家失败。用布尔值记录轮到谁，循环结束后判断上一位成功操作的玩家。

## 复杂度

本题 `n <= 50`，最多只会执行常数次操作；时间复杂度为 `O(1)`，额外空间复杂度为 `O(1)`。

## 边界条件与本地验证

少于 `10` 颗时 Alice 无法进行第一次操作；恰好满足一次操作时 Bob 立即失败。使用 `n=1`、`n=10`、`n=12` 以及能连续进行多轮的值验证。
