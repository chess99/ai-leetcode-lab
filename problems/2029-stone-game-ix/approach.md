# 解题思路

## 思路

## 算法

石子的具体数值只影响总和模 3 的余数，统计余数为 0、1、2 的数量，分别记为 `zero`、`one`、`two`。余数为 0 的石子不会改变当前余数，只影响安全操作的回合奇偶性。

- `zero` 为偶数时，Alice 想存活必须能先从余数 1 和余数 2 中各保留一种选择，条件为 `one > 0 and two > 0`。
- `zero` 为奇数时，余数 0 石子会反转关键局面的回合归属；Alice 只有在两类非零余数石子数量差大于 2 时才能获胜。

## 正确性证明

任意操作后的风险仅由已取石子和对 3 的余数决定，故同余数石子完全等价。余数 0 石子不改变该状态，只交换轮次；成对的余数 0 石子效果相互抵消，因而只需区分其数量奇偶。当 `zero` 为偶数，双方在非零余数间交替以避免和为 0，Alice 需要两类石子均存在才能保有首步安全选择。当 `zero` 为奇数，额外一次轮次交换使得仅当两类数量差超过 2 时 Alice 能迫使 Bob 面对必输状态。算法正是这两个完备条件的直接判定，因此结果正确。

## 复杂度分析

仅扫描一次石子数组，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

## 边界情况

- 所有石子余数为 0 时 Alice 无法获胜。
- 某一类非零余数不存在时，偶数个余数 0 的情形必败。
- 余数 0 数量的奇偶不同，会采用不同的胜负条件。
