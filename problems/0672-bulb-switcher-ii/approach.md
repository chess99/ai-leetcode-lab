## 思路

四个开关的效果都只取决于灯泡编号对 2 和 3 的余数，因此 n 大于等于 3 后，增加更多灯泡不会产生新的状态。又因为连续按同一开关两次会抵消，每个开关的有效按压次数只看奇偶性；四个开关的组合最多形成 8 个满足按压次数奇偶约束的状态。

据此按 n 截断为 1、2、至少 3 三种情况，并按 presses 为 0、1、2、至少 3 分类返回有限表中的状态数。

## 复杂度

- 仅进行常数次条件判断，时间 O(1)。
- 额外空间 O(1)。

## 边界条件与本地验证

- presses=0 时所有灯保持初始状态，只有一种结果。
- n=1 和 n=2 时部分开关效果相同，状态数少于 n 至少为 3 时。
- presses 很大时状态数不会继续增长，重复按压只改变奇偶性。

本地对题目三个示例、零次按压、n=2 的多次按压和 n 大于 3 的饱和状态做最小断言，并执行 py_compile 语法检查。
