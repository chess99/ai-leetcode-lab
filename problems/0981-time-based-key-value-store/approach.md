# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium
- 轮次：1

## 思路

同一个键的 `set` 调用按时间戳递增，因此为每个键保存按时间排序的 `(timestamp, value)` 列表。查询时在对应列表上二分，寻找最后一个时间戳不大于目标时间戳的位置；不存在这样的记录时返回空字符串。

## 复杂度

设某个键已有 `k` 条记录。`set` 为 `O(1)`，`get` 为 `O(log k)`，总存储为 `O(n)`，其中 `n` 是全部写入记录数。

## 边界条件与本地验证

- 未写入过的键、查询时间早于第一条记录，均返回 `""`。
- 查询时间恰好命中记录或落在两条记录之间，取不晚于它的最近一条。
- 本地检查了题目示例以及缺失键、早于首记录的情况。
