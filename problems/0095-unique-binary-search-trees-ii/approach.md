# 解题记录

- 推理档位：medium
- Profile：terra-medium
- 轮次：1

## 思路

递归生成值域 `[lower, upper]` 的所有二叉搜索树。依次选择区间中每个值作为根；小于根的区间递归生成所有左子树，大于根的区间递归生成所有右子树，并对两侧结果做笛卡尔组合。空区间返回 `[None]`，使叶节点和单侧子树能自然参与组合。

## 复杂度

结果数量为第 `n` 个 Catalan 数 `C_n`，必须至少输出这些树。使用缓存避免反复生成同一值域；递归组合时间和保存结果的空间均由输出规模主导，量级为 `O(C_n * n)`；递归深度为 `O(n)`。

## 边界条件与本地验证

- 空子区间返回一个空树候选而非空列表，否则会错误丢失叶节点组合。
- 根值左右严格划分范围，保证每棵生成树满足 BST 性质。
- `n = 1` 返回仅含根为 1 的树；`n = 3` 返回五棵树。
- 本地断言：对 `n = 3` 验证树数为五、每棵中序遍历都是 `[1,2,3]`，且序列化结构互不相同。
