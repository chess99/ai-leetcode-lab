# 解题记录

- 推理档位：medium
- Profile：terra-medium
- 轮次：1

## 思路

统计每个值频率。对约数 `d`，先计算所有 `d` 倍数元素数，组合得到 GCD 为 `d` 的倍数的数对数；从大到小减去 GCD 为 `2d,3d,...` 的已知精确计数。对精确计数做升序前缀和，二分每个查询下标。

## 复杂度

设最大值 `M`，筛式时间 `O(M log M)`，查询 `O(q log M)`，空间 `O(M)`。

## 边界条件与本地验证

重复元素对会正确计入其值的 GCD；查询为 0 基。3 组样例及随机小数组显式生成排序 GCD 对通过，上限约 0.15 秒。
