## 思路

模拟竖式乘法。长度为 `m`、`n` 的两个数乘积最多占 `m + n` 位，先分配该长度的数组。倒序枚举每对数字，乘积应累加到位置 `i + j + 1`；将该位置已有值合入后保留个位，并把进位加入前一格。全部累加后跳过前导零并拼接成字符串。

## 复杂度

两层循环枚举所有数位对，时间复杂度为 `O(mn)`；结果数组长度为 `m + n`，额外空间为 `O(m + n)`。

## 边界条件与本地验证

- 任一输入为 `"0"` 时直接返回 `"0"`。
- 多轮乘积会共享同一位置，必须先与已有值相加再拆分进位。
- 乘积可能少于 `m + n` 位，需要去除前导零。

本地断言 `"2" * "3" -> "6"`、`"123" * "456" -> "56088"`、`"0" * "52" -> "0"`，并以多个小数值对照 Python 整数乘法；同时通过 `py_compile` 语法检查。
