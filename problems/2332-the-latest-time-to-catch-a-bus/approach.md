# 2332. 坐上公交的最晚时间

## 算法

分别排序公交和乘客。按公交发车时间模拟乘客依次上车，记录最后一辆公交实际载客数。若最后一辆未满，候选到达时间是它的发车时间；若已满，候选时间必须早于最后一位上车乘客，即该乘客时间减一。由于不能与任何乘客同一时刻到达，若候选时间已被乘客占用则持续减一，直到找到未占用时间。

## 正确性说明

排序后的模拟严格遵循“最早到达优先登上下一辆有座公交”的规则，因而准确确定了最后一辆公交的剩余座位和最后占座乘客。未满时，最晚能搭乘时间就是发车时间；满载时，必须排在最后一位已上车乘客之前，候选上界为其时间减一。将候选向前跳过已有乘客时间不会影响上车资格，且得到最大不冲突时间，因此结果最晚且可行。

## 复杂度分析

排序时间复杂度为 `O(n log n + m log m)`，模拟和查找时间为 `O(n + m)`，空间复杂度为 `O(m)`。

## 边界情况

- 最后一辆车有空位时可在发车时刻到达。
- 最后一辆车满载时必须早于其最后上车乘客。
- 候选时间连续被已有乘客占用时，需要多次向前调整。
