# 2100. 适合打劫银行的日子

## 算法

预处理 `non_increasing[i]`，表示以第 `i` 天结尾、连续非递增的相邻比较次数；从左向右遇到 `security[i - 1] >= security[i]` 时累加。再预处理 `non_decreasing[i]`，表示以第 `i` 天开始、连续非递减的相邻比较次数；从右向左遇到 `security[i] <= security[i + 1]` 时累加。若两个值都至少为 `time`，该日满足左右条件。

## 正确性说明

`non_increasing[i] >= time` 当且仅当从 `i - time` 到 `i` 的每对相邻天均非递增，满足题目的前置条件。相同地，`non_decreasing[i] >= time` 当且仅当从 `i` 到 `i + time` 连续非递减，满足后置条件。算法只返回同时满足这两个充要条件的下标，因此返回集合恰好是所有适合的日子。

## 复杂度分析

两次线性预处理和一次筛选共耗时 `O(n)`，两个数组占用 `O(n)` 额外空间。

## 边界情况

- `time = 0` 时每个下标的两项计数都满足条件，返回所有日期。
- 数组长度不足 `2 * time + 1` 时没有满足条件的日期。
- 连续相等的安全指数同时符合非递增和非递减。
