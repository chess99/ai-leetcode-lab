## 思路

非递减元音串完全由五种元音分别出现的次数决定。设五个非负次数之和为 `n`，由隔板法可知方案数为 `C(n + 4, 4)`，直接化为 `(n+1)(n+2)(n+3)(n+4) / 24` 计算。

### 正确性

给定五种元音的出现次数，按 `a,e,i,o,u` 顺序拼接得到唯一的字典序非递减字符串。反之，每个合法字符串唯一对应这五个次数。因此答案等于五个非负整数和为 `n` 的解数，隔板法给出的 `C(n+4, 4)` 正确计数所有情况。

## 复杂度

只进行常数次整数运算，时间复杂度和额外空间复杂度均为 `O(1)`。

## 边界条件与本地验证

`n = 1` 时公式返回 5；题目范围内结果和中间乘积都能由 Python 整数安全表示。
