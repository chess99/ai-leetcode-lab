## 思路

使用队列逐层遍历二叉树。每层开始记录当前队列长度，随后恰好弹出这些节点并维护本层最大值，再将其子节点放入下一层队列；一层结束后把最大值加入结果。

## 复杂度

设节点数为 `n`。遍历时间复杂度 `O(n)`，队列峰值不超过树的最大宽度，空间复杂度 `O(n)`。

## 边界条件与本地验证

- 空树返回空数组。
- 节点值可为负数，故每层最大值以负无穷初始化。
- 验证了 `[1,3,2,5,3,null,9] -> [1,3,9]`、`[1,2,3] -> [1,3]`、空树和全负树。
