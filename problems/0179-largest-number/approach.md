## 思路

把每个数字转为字符串，并用比较器决定两个字符串的相对位置：若 `a + b` 大于 `b + a`，则 `a` 应排在前面。对全部字符串按该规则排序后拼接，即得到最大可能数。若首字符为 `0`，说明所有数字均为零，统一返回单个 `"0"`。

## 复杂度

设共有 `n` 个数、单个字符串最大长度为 `d`。排序进行 `O(n log n)` 次比较，每次比较 `O(d)`，总时间为 `O(n log n * d)`；字符串数组与输出占 `O(nd)` 空间。

## 边界条件与本地验证

- 不能按数值大小或纯字典序排序，必须比较两种拼接顺序。
- 前导零需压缩，例如 `[0,0] -> "0"`。
- 较长数字和前缀相同数字都由拼接比较器覆盖。

本地断言 `[10,2] -> "210"`、`[3,30,34,5,9] -> "9534330"`、`[0,0] -> "0"` 及 `[121,12] -> "12121"`，并通过 `py_compile` 语法检查。
