## 算法

一次遍历记录的字符串具有递归形式：叶子 `x` 为 `1 + str(x) + 9`，非叶节点为 `1 + 左子树字符串 + 右子树字符串 + 9`。先枚举有序满二叉树的所有形状（最多为 `Catalan(8)=1430`）。对一个固定形状，按叶子从左到右的次序，可以把字符串唯一写成 `c0 + x0 + c1 + x1 + ... + x(n-1) + cn`，其中 `ci` 只含结构产生的 `1/9`。

将叶序列在中间拆成前 `floor(n/2)` 个与其余叶子。枚举哪些带编号宝石位于前半段；对后半段的所有排列计算模数并计数。后半字符串长度只由宝石集合决定，与其排列无关，所以完整余数满足 `prefix * 10^suffixLength + suffix (mod p)`。枚举前半排列即可直接查找所需的后半余数。宝石始终按下标区分，因此即使数值相同，排列计数也会正确保留其多重性。

## 正确性

递归生成严格覆盖所有有序满二叉树形状且每个形状一次。固定形状后，叶子的从左到右位置固定；将有编号宝石全排列放入这些位置，恰好一一对应题目所说的所有组装方案，包括数值相同但编号不同的宝石。对每个前半宝石集合，算法分别枚举两半全部排列；拼接模数公式精确等价于原字符串拼接，查找的 `need` 因而当且仅当完整记录数模 `p` 等于 `target`。所有集合构成对全排列的不重不漏划分，故累加结果正确。

## 复杂度

设 `a=floor(n/2)`。树形数量为 `Catalan(n-1)`；每个树形枚举所有大小为 `a` 的集合及两侧排列，时间复杂度为 `O(Catalan(n-1) * C(n,a) * (a!*a + (n-a)!*(n-a)))`，空间复杂度为 `O((n-a)!)`。`n <= 9`，最大树形数 1430、单侧最多 120 个排列。

- `p == 1` 时所有方案都满足，直接返回 `Catalan(n-1) * n!`。
- 数值 `0` 的十进制长度按一位处理；大数宝石在拼接前取模，不改变结果。
- 相同数值的宝石仍按编号分别参与排列。
- 两个题面样例分别得到 `1` 和 `4`；对 `n <= 6` 的随机数据，与直接枚举全部树形和叶子排列的 oracle 对拍。
