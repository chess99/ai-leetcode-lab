# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

增加虚拟头节点，使头部重复值可按普通情况删除。`previous` 始终指向确认保留部分的尾部；若当前值与下一个值相同，跳过整个同值连续段并让 `previous.next` 指向第一个不同节点。否则当前节点唯一，两个指针同步前移。

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 边界条件与本地验证

- 使用延迟类型注解，已通过 importlib 独立加载；测试时构造本地 `ListNode` 并实际调用。
- 重复段可能位于头部、尾部，或覆盖整个链表，虚拟头节点统一处理。
- 已排序保证相同值必连续出现。
- 验证：`[1,2,3,3,4,4,5] -> [1,2,5]`、`[1,1,1,2,3] -> [2,3]`、`[1,1] -> []`、`[1,2,3] -> [1,2,3]`。
