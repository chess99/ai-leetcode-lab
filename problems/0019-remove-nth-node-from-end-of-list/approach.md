## 思路

在头结点前加入哨兵节点，使删除原头结点也与其他位置一致。`fast` 先从哨兵走 `n + 1` 步，随后 `fast` 和 `slow` 同时前进；当 `fast` 到达链尾时，`slow` 正好停在待删除节点的前驱。跳过该节点后返回哨兵的下一个节点。

## 复杂度

链表只被线性扫描一次，时间为 `O(L)`，其中 `L` 是链表长度；除哨兵和两个指针外不使用额外存储，空间为 `O(1)`。

## 边界条件与本地验证

- `n` 等于链表长度时，`slow` 留在哨兵，正确删除原头结点。
- 单节点、删除尾节点和删除中间节点都通过相同逻辑处理。
- 题目保证 `1 <= n <= L`，因此快指针预走时不会越过空节点。
- 本地断言：`[1,2,3,4,5], 2` 变为 `[1,2,3,5]`；`[1], 1` 变为空；`[1,2], 1` 变为 `[1]`。
