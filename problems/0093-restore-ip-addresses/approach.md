# 解题记录

- Profile：terra-medium
- 轮次：1

## 思路

回溯依次构造四个 IP 段。每段只尝试长度 1 到 3 的后续子串，跳过有前导零的多位段和大于 255 的段。递归前根据剩余字符数与剩余段数的最小、最大可能长度剪枝；恰好构成四段时收集以点连接的地址。

## 复杂度

深度固定为 4，每层至多尝试 3 种长度，因此搜索节点数量有常数上界；构造输出的时间与有效地址数量成正比。递归路径空间为 `O(1)`（固定四段），不含返回结果。

## 边界条件与本地验证

- 剩余字符不足每段一个或超过每段三个时立即剪枝。
- `0` 合法，但 `00`、`01` 等前导零段不合法。
- 只有用完全部字符且刚好四段时才加入结果。
- 本地断言：`25525511135` 得到两个示例地址；`0000` 得到 `0.0.0.0`；`101023` 得到五个示例地址；长度超过 12 的输入返回空列表。
