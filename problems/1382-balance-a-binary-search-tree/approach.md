## 算法

对二叉搜索树做迭代中序遍历，将节点按值递增顺序放入数组。随后递归处理数组区间：选中点为根，左半区构造左子树，右半区构造右子树。复用原节点并重设其左右指针，因此无需创建新节点。

## 正确性

中序遍历二叉搜索树得到严格递增的节点序列。对任一区间，取中点为根时，左半区所有值都小于根，右半区所有值都大于根；递归构造后仍满足二叉搜索树性质。中点将剩余节点尽量均分到两侧，两个子树的节点数至多相差一层递归规模，递归所得树高为对数级，因而每个节点的左右子树高度差不超过 1，结果是一棵平衡 BST。

## 复杂度

中序遍历与重建各处理每个节点一次，时间复杂度为 `O(n)`。节点数组、显式遍历栈和递归调用合计空间复杂度为 `O(n)`。

## 边界

迭代中序遍历能处理退化为单链的深树，不依赖 Python 的递归深度；单节点树会原样返回。
