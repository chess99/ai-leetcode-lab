# 解题记录

- AI 客户端：Codex Desktop
- 模型：gpt-5.6-terra
- 推理档位：medium
- Profile：terra-medium

## 思路

用一维数组保存到当前行各列的最小路径和。令额外的左哨兵为无穷大，且首格上方的初始值为 0；每个格子的最优前驱只可能来自上方（当前数组值）或左方（前一列更新后的值），因此更新为两者较小值加当前格值。

## 复杂度

- 时间复杂度：O(mn)。
- 空间复杂度：O(n)。

## 边界条件与本地验证

- 第一行只能从左到右累计，第一列只能从上到下累计，哨兵设置同时覆盖两种情况。
- 非负权重无需额外处理负数路径。
- 验证：`[[1,3,1],[1,5,1],[4,2,1]] -> 7`、`[[1,2,3],[4,5,6]] -> 12`、`[[5]] -> 5`。
